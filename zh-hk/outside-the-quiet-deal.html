ECO-30 · 虛構商用庭院 · 15–20分鐘 · 負外部性 · 高斯式議價 · 交易成本

更有利的私人協議，合約之外卻有成本？

議價涵蓋哪些人，會影響結果

高斯最初的分析探討不同制度安排如何改變有害影響的總成本，並明確計入找出相關各方、議價和執行協議的開支。CORE 的經濟學教科書和美國環境保護署的經濟分析指引，解釋了資料、受影響各方和交易成本為甚麼重要。國際貨幣基金組織的一篇解說也區分了私人成本和更廣泛的成本。

英國官方噪音指引說明了另一點：企業傾向採用某項安排，並不會令公眾保障和投訴渠道消失。本個案不把任何英國規則套用於這個虛構庭院；經濟計算也不等於在法律上獲准造成滋擾。

課堂決定

虛構的課堂情境。 工場 A 和錄音室 B 共用一個商用庭院。兩者都在考慮，是否在指定的一個月內，就合法且不具危害性的作業噪音採取額外管制措施。經專業評估的方案均符合所有關於噪音、僱員健康、樓宇及其他方面的強制保障要求。這些額外安排不能免除任何人的法定權利，也不能准許任何人造成滋擾。兩個方案均未實施。

「各自處理」方案由 A 安裝一套局部源頭降噪設備，費用為6,000港元，B 則在自身一方加裝隔音設備，費用為8,000港元。兩項措施合起來可消除模型中 B 所受的滋擾。「協商」方案則把 A 會產生噪音的工序改到 B 不營業的時段，令 A 承擔9,000港元的機會成本，B 則不再有損失。B 向 A 支付5,000港元，雙方平分1,000港元的實際協商及監察成本。「協商」方案不添置設備。

所有數字均為同一個月的完整增量經濟成本，適用時已計入安裝及拆除費用。其後沒有剩餘價值，也沒有遺漏融資影響或無薪勞動。機會成本是扣除因而節省的成本後所放棄的淨盈餘，並非損失的營業收入。5,000港元是 A 與 B 之間的內部轉移支付，並無額外耗用資源。除此之外，相關業務產出和其他效益均維持不變。

A 和 B 已確認這些私人成本，但尚未查明作業時間改動會影響哪些人。沒有依據把雙方的成本當作整個鄰近地區的成本。要決定的是，是否以完成這項查核為前提跟進建議，而不是簽一份犧牲他人利益的協議。各方仍可循原有渠道投訴及依法尋求補救。

各自處理A：6,000港元；B：8,000港元未列明
協商A 放棄9,000港元盈餘；雙方平分1,000港元的交易成本B 向 A 支付5,000港元
你的決定

你會選擇跟進「協商」，而不是「各自處理」嗎？計算 A 和 B 各自的私人成本及合計資源成本，並說明實施前必須查核甚麼。

第二輪 · 多了一項資料

查核整個場地後，發現從事剪輯業務的 C 在建議改用的時段工作，卻未有參與協商。採用「協商」方案，C 在同一個月將損失6,000港元的營運淨盈餘。採用「各自處理」方案，A 的局部源頭降噪措施可避免 C 蒙受這項損失，但 B 仍須自行加裝隔音設備。這是個案就源頭降噪與改變噪音出現時段所設定的技術差異，並非對真實樓宇的量度結果。

第三個方案是「全面降噪」，採用一套費用為13,000港元的源頭降噪設備，消除模型中 B 和 C 所受的滋擾，B 因而毋須加裝隔音設備。要達成並執行一份完整的三方分攤成本協議，蒐集資料、協商及監察合共還需耗用2,000港元。這是該方案的全部交易成本，取代而非加在「協商」方案的1,000港元之上。所有成本均尚未發生，可以避免，沒有沉沒成本。

C 損失的6,000港元是實際放棄的淨盈餘，不是付給 A 或 B 的款項，也不是生意僅僅轉到區內另一家企業。這個刻意限定範圍的貨幣模型，不計入其他因方案而異的損害或效益。非金錢方面的考慮和法定權利仍是獨立約束，不能假定可用金錢買下。補償 C 只會重新分配金錢，並不會消除該項生產損失。

比較「各自處理」、計入 C 損失後的原有「協商」方案，以及按所列交易成本計算的「全面降噪」。成本較低的調解途徑或可降低「全面降噪」的交易成本，但目前未有低於2,000港元的報價。即使較安靜的作業環境會令 C 受益，任何人也無權單憑這一點向 C 收費。

你的決定

現在哪個方案在模型中的總成本最低？解釋為甚麼補償不等於降噪，並找出「全面降噪」的交易成本上限，使其總成本不高於「各自處理」。

雙方成本的計算結果

採用「各自處理」，A 承擔6,000港元，B 承擔8,000港元，合計14,000港元。採用「協商」，A 承擔的成本為9,000港元 − 5,000港元 + 500港元 = HK$4,500；B 承擔的成本為5,000港元 + 500港元 = HK$5,500。雙方分別節省1,500港元和2,500港元。合計成本為10,000港元，雙方合計的私人得益為4,000港元。

轉移支付在合計時互相抵銷：9,000港元實際機會成本 + 1,000港元交易成本 = 10,000港元。不要再加5,000港元。可以有條件地跟進建議，但在實施前，須查明受影響各方、核實影響，並維持所有強制標準和權利。協議令簽署方得益，不等於一定能改善整體社會的處境。

納入其他受影響方後的比較結果

計入 C 的損失後，原有「協商」方案的成本為9,000港元 + 1,000港元 + 6,000港元 = HK$16,000。「各自處理」的成本仍為6,000港元 + 8,000港元 = HK$14,000，而模型中的 C 並無損失。「全面降噪」的成本為13,000港元 + 2,000港元 = HK$15,000。在這三個已列明價格的可行方案中，應選「各自處理」。

單計技術措施，「全面降噪」成本較低；計入議價開支後便不再較低。這不是說各自投資必然最好，也不是說政府絕不應介入。這項比較只限於題目所列的方案。未知的外部影響、執行協議的困難或新報價，都可能改變方案的排序。

轉移支付不會令損失消失

在這個簡化的貨幣模型中，如果 A 和 B 向 C 補償6,000港元，C 的私人淨得益可回復至原來水平。但盈餘的損失仍然存在：一方收取的款項正是另一方付出的款項，合計時互相抵銷。未計為商議補償而額外付出的成本，原有「協商」方案的成本仍為16,000港元。補償也不能換取違反強制保障要求或侵犯他人權利的許可。

相比「各自處理」，A 和 B 合共只節省4,000港元，C 卻損失6,000港元。按所列成本，兩者的得益不足以全數補償 C，同時又令三方的處境都不比原來差。因此，除了總額，還須考慮得失如何分配，以及各方是否自願參與。不要把 C 未獲納入協商僅僅視為行政上的不便。

交易成本的臨界點

設 T 為「全面降噪」的全部交易成本。當13,000港元 + T = 14,000港元，兩個方案的成本相同，因此 T = 1,000港元。低於1,000港元，「全面降噪」確實較便宜；等於1,000港元，兩者成本相同；高於這個數額，「全面降噪」便較昂貴。2,000港元的報價超出這個上限。不要假定有免費的調解員，也不要忽略參與者所花的時間。

當 T = 1,000港元，A 和 B 原則上可以分攤14,000港元的總成本，分別支付6,000港元和8,000港元，C 則毋須付款。這樣，各方的私人得失便與「各自處理」相同。這項計算只說明在各方自願同意下可行，並非預測議價結果。若交易成本低於上限，便可能有盈餘可供分配，但仍須視乎證據、權利及各方能否達成協議。

教師說明

分開記三本帳：實際降噪成本、實際損失的盈餘，以及轉移支付。計算總額時，只計首兩項及實際交易成本。模型以同一個月為比較基準，並非把資本設備的購置價與全年損失相比。C 的損失並非對健康影響的估值，符合法例也不代表沒有經濟外溢影響。

SUS-04 問的是，誰為無法排除他人享用的共享效益出資。本個案的原有合約則把不利影響轉到另一時段，並遺漏一家受影響的企業。高斯的零交易成本基準是分析問題的工具，並不是說現實中的議價自然會涵蓋所有人，或帶來公平的分配。

來源與個案假設 · 選讀

課堂決策所需的資料，上文已經齊備。來源只供選讀，用來交代出處和背景。

所有企業、技術效果及港元金額均屬虛構，並以同一個月為準。各方案均符合強制保障要求，各方保有原有權利，並不構成造成滋擾的法律許可。「各自處理」透過 A 的源頭降噪避免 C 蒙受損失；「協商」改動作業時段，令 C 蒙受損失；「全面降噪」消除兩家受影響企業所受的滋擾。所列成本完整且尚未發生，沒有沉沒成本或剩餘價值。C 損失的是淨盈餘，不是營業收入，也不是生意轉到別處。5,000港元的轉移支付在合計時抵銷；計入 C 後，原有「協商」方案的總資源成本為16,000港元。「全面降噪」以2,000港元取代1,000港元的協商成本，不是兩筆都計。個案沒有聲稱找出了更廣泛的社會最優方案。
