OPS-30 · 香港 · 15–20分鐘 · 批次譜系 · 可追溯性 · 模擬回收

一個生產批次，就只有一個回收範圍？

報道帶出的問題

可追溯性標準要求把經加工的投入物料與產出連繫起來。這項虛構的預先設計練習，探討物料跨批流動時，細分生產批次的編碼是否仍然有用。

課堂決定

虛構的香港食品包裝商 Bay Pantry 正為日後的乾身小食包裝流程設計記錄方式。這是一項桌上模擬回收練習，所用數量均屬虛構，配料流向亦為模擬；沒有任何食品不安全，也沒有食品獲放行或出售。食物安全主管已訂定所有適用的食物安全、通報、下架及處置程序，學生不得放寬要求。個案設定兩個方案只要按規定實施，均符合適用要求。要決定的是追溯記錄要再細分到甚麼程度，而不是是否合規。

一天有 A、B、C 三個生產批次，分別生產600、400和800包。每包按所選方案的批次層級獲編一個識別碼。D 方案把全日產量編為一個批次，記錄當天所有配料來源及成品去向，需時四個員工分鐘。R 方案分為三個生產批次，逐批記錄配料投入及成品去向，每批需時四分鐘。其餘記錄及作業工作完全相同。兩個方案均在經理可負擔的範圍內；如果額外八分鐘能為縮小管控範圍提供充分依據，經理較傾向 R。日後回收可節省多少成本，並無金額估算。

生產批次包數初始配料及流程假設
A600只用配料 X；投入、產出及去向的關聯記錄完整。
B400只用配料 Y；投入、產出及去向的關聯記錄完整。
C800只用配料 Z；投入、產出及去向的關聯記錄完整。
隔離所有生產批次各批次的投入物料、工具和工序均分隔；沒有轉移、殘留帶入、共用返工物料或其他跨批關聯。
練習規則所有衍生產出如發現配料 X 涉事，須管控所有可能含有 X 的產出。只有所選方案的記錄及經核實的實物證據足以支持，才可縮小範圍。D 無法按生產批次區分各包成品，R 則可以。
你的決定

你會選擇哪個方案來記錄日後的批次？按初始假設，若配料 X 涉事，每個方案各自能支持把多少包納入管控範圍？

第二輪 · 多了一項資料

在 R 的桌上測試中，觀察員附有時間標記的練習記錄顯示：在 B 批共400包的物料混合之前，曾模擬把配料 X 從已開封的容器轉入 B 批。擬用的生產批次記錄仍寫着「只用 Y」，因為沒有記錄轉移的欄位，也沒有審批步驟。觀察員的證據足以證實曾發生轉移，卻無法在 B 批內識別出更小的涉事範圍。A 批的600包仍與 X 有關聯。

練習中的獨立證據確認，C 批使用密封的 Z，在實體分隔的生產線上以專用工具處理，沒有轉移、返工或透過共用工序接觸其他批次。個案刻意限定範圍，沒有其他產出或剩餘配料。A 和 B 的下游去向記錄完整。C 批可以排除在外，靠的是這些經核實的事實，而不只是編碼不同。團隊必須修正原型並重做測試，才可在日後投入生產；這次模擬並不授權放行任何實際食品。

你的決定

模擬的配料轉移揭曉後，練習中有充分依據的管控範圍是甚麼？較細分的方案在獲准用於日後生產前，必須作出哪些改動？

初步選擇

選擇 R，但前提是記錄與實際物料流向相符。D 需時四分鐘，只能以全日1,800包為管控範圍。R 需時12分鐘，多花八分鐘；在所述的完全分隔條件下，與 X 有關的管控範圍可限於 A 批的600包。範圍有望減少1,200包，但這並非預期可節省的成本，也不是對實際事故的保證。若能接受較廣的管控範圍，D 仍是有理據的較簡單選擇；兩個方案均不得省略必要的安全步驟。

追查配料流向，不只看標籤

轉移揭曉後，與 X 相連的產出有兩批：A 批600包和 B 批400包。因此，練習的管控範圍是這1,000包及其下游去向，而非只有 A 批。由於 B 批物料已混合，無法識別更小的涉事範圍，因此 B 批全部400包都須納入。這項練習的範圍已明確限定，C 批的800包之所以可排除，全憑獨立證據證實批次之間確有分隔。若是真實事故，仍未釐清的關聯須上報處理，並採取適當審慎的管控範圍，不能先行假定可以排除。

補全反映實際物料流向的批次譜系

為每次轉移新增記錄，連結來源配料的批次及容器、數量及單位、時間、接收的生產批次及負責操作的員工。除了按計劃投入的配料，也要記錄追加、退回、殘留帶入及返工。把每項經加工的投入物料與產出批次編碼、成品包數及去向連繫起來。事發當時便須填報，並在確認接納該批完整記錄前加設核實步驟。數量有助核對物料流向，但總數吻合本身並不能證明哪些成品含有某項配料。

使用前重新測試

再次進行雙向模擬追溯：由 X 追查至所有產出去向，再由 B 反查每項配料的來源。加入一次非預期的轉移，檢查修訂後的記錄能否在不依賴觀察員獨立補救記錄的情況下，找出 A–B 之間的關聯。記下缺漏及糾正措施，待證據齊全才批准原型。增加識別碼，並不能令共用物料的批次各自獨立。只有事件記錄和實物管控措施能支持所劃定的範圍，細分批次才可讓追溯更精確。

教師說明

先發放開場情境及表格，再提出 Q1。揭示模擬轉移後，先問 Q2，再公布兩題答案。畫出 X 流向 A 和 B，另畫 Z 單獨流向 C。核對算式：600 + 400 + 800 得1,800；三乘四分鐘得12分鐘；600 + 400 得1,000。請學生質疑「編碼不同就代表安全」和「任何情況都要管控全日產量」這兩種說法。這是為日後生產而做的設計及模擬練習，並非建議延誤實際回收，或違反主管當局指示而排除產品。
