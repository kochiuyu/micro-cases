OPS-17 · 香港 · 10–15分鐘 · 綜合計劃 · 團隊延續性 · 存貨與積壓

維持產量，還是跟隨訂單高峰？

產能也取決於人手

2026年9月22日，香港勞工及福利局發表更新的人力推算，指出多個職業的人手壓力持續。這只是人力規劃的大背景，並非對下文那家工場的預測。個案內的訂單、產能、成本和人手安排均為原創虛構設定。

課堂決定

一家虛構的香港工場只生產一款規格不變的標準收納箱。為期六個月的周期開始前，工場須在兩個已擬定的方案中選一個。L 保留五個由受訓員工擔任的生產崗位，每月生產100個收納箱。C 則按每月訂單調整受訓人手的崗位數目，不留存貨，也不延遲交付。每個有員工上任的崗位每月可生產20個收納箱，不論忙閒，當月成本都是20,000港元。兩個方案開始時均有五個崗位，下一周期開始前也須恢復至五個。生產600個收納箱所需的物料及其他共同成本已有撥款，兩個方案的金額相同，比較時不計。

工場透過人力中介派駐員工，安排合法並經各方自願同意。每增設一個由合資格員工擔任的崗位，成本為3,000港元，已包括在需要人手前一個月完成的有薪入職培訓。每結束一項派駐安排，成本為2,000港元，已計及所有規定的通知及合約款項。另行派駐的安排、安全工作上限、培訓和員工權益均有保障。所有人手變動均須預先安排；兩個方案都不依賴即時招聘或無薪待工。這些簡化的成本數字只供教學假設之用，並非僱傭法律意見，也不是實際工資水平。

期初的製成品存貨和積壓均為零。每個月底，製成品存貨不得超過40個收納箱，持貨成本為每個每月100港元。一名客戶已明確同意，原定第5個月交付的收納箱，最多可有20個改在第6個月送達；每個延遲交付的收納箱須支付1,000港元，已包括所有相關款項。除此之外，不得延遲交付。這是雙方同意、可選用的服務調整，並非容許失約。每月先完成生產，再於月底發貨；如有較早積壓的訂單，須優先交付。兩個方案期末的存貨和積壓均為零。只比較兩個已擬定的方案，不聲稱找出全局最優方案。

第二輪 · 多了一項資料

在工場尚未調整人手或開始生產之前，客戶把60個收納箱由第5個月改到第6個月交付。各月的訂單量現為80、80、140、80、80、140，總數仍是600。所有變動仍可按所需的培訓前置時間預先安排，沒有已成為沉沒成本的調整開支。原先可選用的延遲交付安排已無需要；所有修訂後的訂單均須在各自的新交付月份送達。

L 可繼續每月生產100個收納箱。C 可把各月的崗位數目改為4、4、7、4、4、7，期末仍恢復至五個。一名經理提出 C 系列的第三個方案：在第4和第5個月保留全部七個由受訓員工擔任的崗位，而不是先減至四個，再增補人手。這些員工仍獲全薪，但每月只生產當月應交付的80個收納箱；這個留任方案不會增加存貨，也不會安排員工做其他有產出的工作。這樣可以維持團隊的延續性，免去一次削減三個崗位、其後再增補的調整。個案沒有量化品質、員工留任或未來生產力方面的好處。成本條件及員工權益保障維持不變。

你的決定

第二個高峰推遲了，你會怎樣修改方案？比較 L、修訂後的 C 和有薪留任方案，並說明為甚麼訂單總量相同，不代表交付時間不同所帶來的成本也相同，更不代表有一套放諸四海皆準的人手安排。

逐月追蹤存貨結餘

採用 L，各月月底的淨存貨為20、40、0、20、−20、0。負數代表有20個收納箱經客戶同意延遲交付，不是實物存貨為負數。持貨量按月累計為20 + 40 + 20 = 80個箱月，成本為8,000港元。議定延遲交付的成本為20,000港元。五個崗位維持六個月，成本為600,000港元，計入比較的成本合共628,000港元。存貨沒有超過40個收納箱的上限。

別漏算期初和期末的人手調整

原來的 C 方案各月設4、4、7、4、7、4個崗位，合共30個崗位月，成本為600,000港元。由五個崗位起步，期末再恢復至五個，合共須增補七個崗位，並結束七項派駐。調整成本為7 × 3,000港元 + 7 × 2,000港元 = 35,000港元。C 的總成本為635,000港元，沒有存貨或延遲交付。L 少花7,000港元，但用上了議定的交付調整安排；若較重視按原定月份交付，選 C 也有道理。

高峰一推遲，逐月結餘就不同

按修訂後的訂單時間表，L 各月月底的存貨為20、40、0、20、40、0個收納箱。持貨量合共120個箱月，成本為12,000港元；沒有積壓，總成本為612,000港元。修訂後的 C 仍需30個崗位月，但計入期初減員及期末恢復至五個崗位後，只需增補六個崗位、結束六項派駐。調整成本為30,000港元，總成本為630,000港元。

維持團隊延續性有代價

在兩個淡月均保留七個崗位，會多出六個有薪崗位月，即120,000港元。這樣可以免去結束三項派駐和其後增補三個崗位，節省15,000港元。與修訂後的 C 相比，成本增加105,000港元，總額為735,000港元。維持團隊延續性或有未反映在所給數字裏的價值，但在本個案中不能說它能節省成本。反過來說，這些虛構成本也不能證明頻繁調整人手通常是好做法。

教師說明

要求學生逐月計算存貨結餘，不要把600個訂單單位平均成每月100個就算了。任何負結餘都要標為積壓，並核實客戶是否同意延遲交付。期初和期末的人手變動都要計入。若學生說明其服務偏好，可接受他們選擇原來的 C。按所給的修訂後成本，L 是三個方案中成本最低的，但並未證明它是全局最優方案。不要自行假設有無薪待工、即時培訓、工資損失、未經同意的延遲交付，或把技能帶來的好處量化。產品始終不變；個案討論的是綜合計劃中的時序安排，不是延遲差異化。
