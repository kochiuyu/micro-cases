已投放半年，還要再投一個月嗎？

要繼續，就得有着眼未來的理由

過往投入的心血，容易令人覺得放棄項目就是浪費。當人只顧為先前的選擇辯護，不再重新評估下一筆投入可以帶來甚麼成果，便會出現承諾升級。不過，繼續投入仍可能合理：應比較未來的增量成本、收益和替代方案，而不是認定堅持或退出本身就一定可取。

課堂決定

Harbour Roster 是一家虛構的香港排程初創企業。兩名成年創辦人已花了六個月和300,000港元開發新產品。不論採用哪個方案，這筆錢都無法收回；在本練習中，已完成的程式碼也沒有可獨立出售或重用的價值。當中一名創辦人認為，現在叫停，就等於白費了那六個月。

他們必須在兩個方案中擇一：C 是出資進行最後一輪為期一個月的開發；S 是立即停止開發這款產品。C 需要投入60,000港元新資金，以及創辦人可用於項目的時間，目的是達到一項指定的技術階段目標：在已議定的一組測試中可靠地檢查排程衝突。目前未有批准任何付款，也未有批准加開一輪開發。

若 C 達到階段目標，扣除其後所有開發、交付、銷售及支援成本後，後續產品機會的題設現值為200,000港元；若未能達標，現值為零。這些結果價值尚未扣除該輪開發成本60,000港元；不論是否達標，這筆成本都要支付。

若選 S，創辦人可以改為承接一項現有、為期一個月的顧問工作，扣除所有相關現金成本後，確定可取得20,000港元的淨現值盈餘。這項工作與 C 同樣佔用創辦人的時間，兩者不能兼做。若選 C，便會錯過這項工作，既不能延期，也不能分判。

不論選哪個方案，另行預留且不得挪用的款項，加上有薪支援團隊，足以履行所有現有的客戶、員工和供應商義務，以及行政責任。履行這些義務並不取決於新產品能否成功。兩個方案都無須動用這筆款項便可負擔。停止這項開發不等於立即解散企業，也不代表可以取消支援、扣起薪酬或轉移客戶資料。

在本練習中，創辦人同意以預期增量金錢價值最高為目標。他們最初評估達標概率為60%。所有金額均以今日價值表示，無須再折現。除已列明的結果價值和顧問工作盈餘外，個案並不假設兩個方案在殘值、學習、聲譽、稅務、結業或未來機會的價值方面有任何差異。

按最初評估的60%，比較 C 和 S 的未來預期價值。已花掉的300,000港元應否納入比較？達標概率是多少，兩個方案才會不相上下？

第二輪 · 多了一項資料

一名獨立工程師測試了尚未解決的整合問題，提出一項獲採納的新規劃估算：在最後一輪開發中達標的機會只有30%。請把這個概率視為練習的修訂參數，而不是經測量得出的確定值。該輪開發成本、不同結果下的價值、可承接的顧問工作，以及已有保障的義務，全部維持不變。

第一名創辦人說：「都已經花了300,000港元和六個月，現在不能停。」第二名創辦人則問，接下來這60,000港元是否仍值得投放。沒有新證據支持原先60%的估算；題目也沒有提供成本較低的測試、延長開發週期或其他融資安排作為第三個選項。

你的決定

按已採納的30%估算，你會維持還是改變開發決定？把繼續開發的成本與放棄顧問工作的機會一併考慮。說明過往投入能帶來甚麼啟示，但不要把這筆投入當成再花錢就能收回的收益。

講評 · 從今天算起

達標概率為60%時，C 的預期結果價值為 0.60 × 200,000港元 + 0.40 × 0港元 = 120,000港元。扣除新一輪開發成本60,000港元後，得出60,000港元。S 的顧問工作帶來20,000港元，因此 C 最初的預期優勢為40,000港元。

換個算法，C 的預期收益為120,000港元，比現金成本60,000港元加上機會成本20,000港元的總和多40,000港元。不要把顧問工作盈餘扣減兩次：可以直接比較兩個方案，也可以在增量計算中把放棄的盈餘扣減一次。

講評 · 按證據修訂判斷

達標概率降至30%時，C 的預期結果價值跌至60,000港元。扣除60,000港元的新成本後，預期淨值為零。S 仍可帶來20,000港元。按已議定的預期價值準則，現在停止開發並承接顧問工作，會比繼續開發多帶來20,000港元的預期價值。

與甚麼都不做相比，新一輪開發僅能打和；與可承接的顧問工作相比，則不及後者。達標仍然有價值，但預期收益已不足以同時抵銷新增現金成本和放棄另一方案所失去的盈餘。選 S 不會妨礙履行任何已有保障的客戶義務。

講評 · 找出臨界點

設 p 為達標概率。C 的價值為 200,000p港元 − 60,000港元；S 的價值為20,000港元。兩者相等時，200,000p港元 = 80,000港元，因此 p = 40%。在其他題設假設全部不變的情況下，p 高於40%時，C 較佳；等於40%時，兩者相同；低於40%時，C 較差。

最初採用的60%高於臨界點，修訂後的30%則低於臨界點。建議有變，是因為未來前景有變，而不是因為先前的開支消失了。如果預測確有改善，或尚須支付的成本下降，便可能值得再評估；但重複引用舊有概率並不構成新證據。

講評 · 分清沉沒支出與現有資源

不論選 C 還是 S，300,000港元都已花掉。若從兩個方案同時扣除這筆金額，兩者的總值只會等額下降，排序不變。若把這筆錢當成繼續開發就能「收回」的收益，便是憑空加上一筆現金流入。已花的時間也一樣：今天已無法把那六個月改作其他用途。

過往的工作仍可提供有用的技術資料。應利用這些資料改善對未來的預測，並記下所得經驗。若有可轉售的資產、可強制履行的承諾，或可重用的程式碼，就需要另作處理；本個案已明確說明，兩個方案在這些方面並無價值差異。歷史成本不能當作當前的機會成本。

講評 · 不要單憑結果判斷決定

即使最終結果欠佳，也不能證明當初按60%作出的決定不合理。同樣，差劣的決定即使碰巧成功，也不能證明只憑沉沒支出作決定的理據成立。應以作決定時掌握的資料、可行的方案和適用的準則來評估該決定。

再撥款前，先記下已採納的概率、餘下成本、各結果下的價值及40%的臨界點。獨立技術檢查有助創辦人重新審視自己對項目的執着，但也不是萬無一失。現實中的創辦人可能有不同的風險取向或其他合理目標；應把它們明確說出來，而不是用「必須證明過往支出是值得的」來掩蓋。

教師說明

不要把已受保障的支援預算納入這次可酌情決定的比較：不論選哪個方案，這筆預算仍然可用，也仍然有其必要。請學生先寫出兩個方案各自的價值，再用一次機會成本計算得出相同的差額。最後問：如果沉沒金額倍增，而所有與未來有關的條件維持不變，決定會否改變？

ENT-20 由決定結業之後開始，梳理如何妥善履行承諾。本個案尚待決定的是，再做一輪開發是否值得。STR-11 要在現有產品線之間分配開發資源，但沒有提供未來回報；本練習則提供概率及各結果下的價值，以集中探討如何按證據更新判斷，以及承諾升級。
