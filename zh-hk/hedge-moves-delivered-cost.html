FIN-28 · 香港 · 15–20分鐘 · 基差風險 · 商品風險 · 情景現金成本

對沖在動。它會隨我們的成本一起動嗎？

參考價格，並不總是到貨價格

芝加哥商品交易所（CME）說明，本地現貨價格可以不同於參考期貨價格，原因包括運費、質素和本地供應狀況。倫敦金屬交易所（LME）的教材同樣把基準參考價格和實物溢價分開。抵消基準價格的變動，並不會自動把送到貨的賬單鎖死。

本個案只給出一個虛構的對沖損益，供算術使用。它不是落盤指令，也不要求挑選真實工具，或套用對沖會計。

課堂決定

一間虛構的香港加工商，必須在一個月內正好買入1,000公斤工業投入品。數量、質素和交貨日都已固定。供應商的每公斤全部送到價格，將是該日的參考指數I，加上本地溢價P。本模型沒有其他交貨費用、稅項或匯率影響。起初的計劃假設是P = 每公斤10港元，但這項溢價並沒有寫進合約。

團隊比較完全不對沖，以及一項課堂允許的對沖：正好覆蓋1,000公斤，並且用同一個指數觀察日。結算時，對沖向加工商支付1,000公斤 × (I − 100港元/公斤)。結果若為負，加工商就按絕對值支付該金額。固定的對沖費用總計2,000港元。結算和實物採購發生在同一天。本練習規定資金充足、沒有違約、沒有數量錯配，也沒有額外的融資或交易成本；真實的抵押和流動性要求，不在這個簡化損益模型之內。

管理層寫明的目標，是去掉採購成本裏由指數帶動的波動，而不是在每一種不對沖的結果裏都更便宜。它還要問：這個計劃能否保證全部採購成本不超過115,000港元。第一次計算使用給定的兩種指數情景，以及10港元的計劃溢價。沒有給出概率。請計算不對沖成本，以及對沖後的淨現金成本，然後選擇怎樣描述這種保護，以及這種描述的限度。沒有授權，也沒有要求建立任何真實財務頭寸。

不對沖成本 = 1,000 × (I + P)。對沖後淨現金成本 = 實物採購成本 − 對沖收款 + 2,000港元。若收款為負，減去它就等於加上這筆對沖付款。

你的決定

給定的對沖，能否達到去掉指數風險這一目標？兩種情景下的現金成本是多少？115,000港元的全部成本上限，能不能稱為已經保證？

第二輪 · 多了一項資料

在作出任何承諾之前，本地裝卸能力中斷，使每公斤25港元的溢價成為說得通的壓力情景，而且與指數無關。供應商的定價公式仍是I + P；對沖公式、數量、費用和日期都不變。請用P = 25把兩種指數情景重算一遍。這是壓力測試，不是預測，也不是指定的概率。

本練習沒有固定溢價的供應商要約，也沒有再加一層溢價對沖。管理層可以把指數對沖留作部分保護，也可以放棄，但不能把剩下的溢價風險說成已經消除。只要突破115,000港元的計劃上限，就必須報告，並另尋修訂後的採購計劃，而不能聲稱同一個指數對沖已經蓋住本地那一部分。

你的決定

有對沖和沒有對沖時，壓力之下的現金成本是多少？剩下的風險，以及採購上限這個問題，管理層應當怎樣描述？

第一個答案：對沖抵消的是甚麼

當I = 120且P = 10時，實物成本是130,000港元。對沖收款是20,000港元，因此淨成本是130,000 − 20,000 + 2,000 = 112,000港元。當I = 80時，實物成本是90,000港元；負的20,000港元收款其實是一筆付款，因而得到90,000 + 20,000 + 2,000 = 112,000港元。

溢價和數量保持不動時，給定的對沖去掉了指數造成的波動。在低指數情景裏，它比繼續不對沖更貴，這並不是所述降風險目標的失敗。第一組快照的兩個結果都低於115,000港元，但溢價只是假設，並未固定，所以得不出無條件的上限保證。

第二個答案：溢價單獨在動

當P = 25且I = 120時，不對沖成本是145,000港元，對沖後成本是145,000 − 20,000 + 2,000 = 127,000港元。當I = 80時，不對沖成本是105,000港元，對沖後成本是105,000 + 20,000 + 2,000 = 127,000港元。兩個對沖後的壓力成本，都比115,000港元的上限高出12,000港元。

直接把剩餘部分看出來

代入後，對沖成本 = 1,000(I + P) − 1,000(I − 100) + 2,000 = 102,000港元 + 1,000P。指數消掉了，溢價沒有。把P從10提高到25，淨成本增加15,000港元。按本模型，溢價須不超過每公斤13港元，才能留在115,000港元以內。

參考價格上的風險，和實際送到貨的風險並不相同，這種錯配就是基差風險。公式在這裏把它乾淨地分開了；真實對沖還可能有日期、等級、數量、資金和其他錯配。不要假設參考價格和本地溢價總是一起走，或總是反着走。

保留精確的說法，而不是全部成本的保證

就所述目標而言，把給定對沖留作只針對指數的保護，仍然說得通。它讓壓力下的淨成本在兩種指數情景裏保持不變，但滿足不了溢價壓力下那個單獨的全部成本上限。放棄對沖，指數風險和溢價風險都會留下；低指數時更便宜的那一個結果，並不能保證賬單更低。

要報告剩餘的溢價，以及12,000港元的壓力差額。管理層需要一份修訂後的採購或資金計劃，以及任何進一步獲授權的分析；這裏沒有另外發明工具或供應商協議。只有情景比較，又沒有指數和溢價的聯合分佈，就不能確立預期節省，也不能說總成本的方差普遍下降。

教師說明

先給四分鐘，核對起初的兩筆現金。然後揭開溢價壓力，要求在簡化公式之前再核對兩筆。留意負數的對沖收款：它會增加買方的現金成本。追問：說到指數風險下降時，甚麼被按住不動。

所有價格、合約條款和費用都是編出來的。這是給定的損益，不是某張上市合約的規格，不是投資建議，也不是真實交易。不要講授具體的交易操作步驟，也不要把期末淨成本說成現實裏的流動性需要。和外幣收支的自然抵消不同，實物送到貨的風險裏，有一塊對沖並沒有覆蓋的本地部分。

所有主體、數量、價格和損益條款都是虛構的。沒有要求做真實衍生品交易、發出交易指令或做會計處理。資金和期末結算上的簡化已經寫明；真實的抵押和流動性風險仍在這道算術之外。三份倫敦金屬交易所材料是同一家交易所的教材，不是彼此獨立的實證證據。
