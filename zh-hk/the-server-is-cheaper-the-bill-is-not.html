IS-47 · 香港 · 15分鐘 · 雲端服務收費 · 用量計量 · 成本敏感度

伺服器較便宜，帳單也會較低嗎？

一張雲端服務帳單，不只按一種用量收費

Google Cloud 的 Cloud Run 文件分別說明多種資源用量的收費。AWS 公布 Lambda 按請求次數和執行時間計費的各項因素，另有文件說明用量承諾。香港一家相片沖印店有兩個假設方案，所列港元費率均屬虛構，並非供應商報價。

課堂決定

兩個方案的檔案保留安排、高峰處理量、客戶回應時間和服務質素均相同。Flex 按請求次數和 CPU 時間分別收費。Reserved 按月收取固定套費，涵蓋所列兩種工作量下的全部運算用量和請求。最短合約期為一個月。沖印店必須在同一個下月續約日選定其中一個方案，轉換方案毋須繳付罰款。

首次用量計量演練錄得 2 百萬次調用、100,000 CPU 秒、向客戶傳出 300 GB 數據，以及 50 GB·月的儲存用量。計費用量已計及任何取整。兩個方案的用量相同，但報價所列的網絡費率不同。假設沒有稅項、抵扣額、支援服務費、罰款或其他成本。

你的決定

根據首次完整的用量計量演練，你會推薦哪個方案？計算兩個方案的帳單總額，並說明計入對外傳輸收費後，原本只比較運算相關收費所得的差額有何變化。

第二輪 · 多了一項資料

同一次續約前測試現已把內部佇列短暫中斷後的重試納入計算。全月預測用量增至 2.5 百萬次調用和 180,000 CPU 秒，但對外傳輸的位元組數和保留的儲存用量均沒有增加。作業在內部重跑，Reserved 的套費仍涵蓋全部工作量。

你的決定

你會改變選擇嗎？若調用次數為 2.5 百萬次，傳輸及儲存用量維持不變，CPU 總用量要達到多少秒，兩個方案的收費才會相同？

看完整份報價

按首次演練的用量計算，Flex 的收費是 160 + 150 + 360 + 30 = 700港元；Reserved 的收費是 650 + 90 + 30 = 770港元。Flex 仍便宜70港元，但計入對外傳輸收費後，Flex 在運算及請求收費上的優勢由340港元縮至70港元。

按變動後的用量重新計算收費

計入重跑的作業後，Flex 的收費是 200 + 270 + 360 + 30 = 860港元。Reserved 仍是770港元，現在反而可節省90港元。Flex 多出的160港元，包括額外調用的40港元和額外 CPU 時間的120港元。

收費相同的用量

調用次數為 2.5 百萬次時，Flex 不計 CPU 的收費為590港元。與 Reserved 總額770港元相差180港元；按每秒0.0015港元計算，這筆差額可支付 120,000 CPU 秒。低於這個用量，Flex 較便宜；高於這個用量，只要套費仍涵蓋全部工作量，Reserved 就較便宜。

教師說明

問學生：為甚麼把運算用量當作固定不變來估算，與採用只顯示不重複客戶訂單的儀表板，會以不同方式漏掉同一個問題？請學生索取一份帳單明細，列出每個計量項目的單位、用量和費率，並核實帳單月份和網絡路徑是否與比較所用的一致。

來源與個案假設 · 選讀

課堂決策所需的資料，上文已經齊備。來源只供選讀，用來交代出處和背景。

所列費率和方案均屬虛構，不構成產品建議。毋須另行格價。

  1. Google Cloud, Cloud Run pricing。說明不同資源如何按用量分別收費，以及計費粒度；並非本練習的報價。
  2. AWS, Lambda pricing。分別說明請求量和執行時間，並在適用時列出額外的網絡或數據傳輸條款。
  3. Google Cloud, billing export。有關標準版及詳細版匯出資料的說明涵蓋用量、SKU、成本、幣別及資源層級的欄位。
  4. AWS, how Savings Plans apply。例子區分承諾用量及承諾範圍以外的按需用量；兩者均不等同個案中的虛構固定套費。
  5. Google Cloud, invoice cost details。成本表按帳單期逐項列出費用，並提供 CSV 檔案，方便將用量估算與帳單核對。
