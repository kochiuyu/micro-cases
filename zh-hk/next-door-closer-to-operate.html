STR-39 · 香港及兩個虛構的亞洲城市 · 15–20分鐘 · 國際市場選擇 · 多維距離 · 營運調整

市場就在隔鄰，營運就更容易？

距離不只是路程

國際策略研究所說的距離，不限於地理上的遠近。出口指引同樣提醒企業，除了出差安排，還要了解客戶的做法、語言、許可要求和付款安排。這些都是值得查證的事項，不能據此從國籍推斷商業行為。以下比較採用的是針對特定客戶的虛構資料，並非對真實國家的描述。

課堂決定

虛構企業 FrameDesk 以香港為基地，協助企業客戶把日常行政流程整理成文件。公司正為首次服務出口試行計劃選一個地點：較近的亞洲城市 N，或較遠的城市 F。兩個城市代號都是虛構的，並非借代號影射任何具名的司法管轄區。這項服務不提供任何受規管的法律、醫療或工程專業意見。

兩組候選客戶均已通過相同的需求及付款可靠性審查。比較假設在任一城市均完成六個項目並收妥款項；扣除一般服務交付成本後，邊際貢獻為180,000港元，尚未扣除另列的市場進入成本。這個條件一致的情景並非銷售預測，也不代表已有客戶簽約承諾委託六個項目。

公司只有一支已獲撥款的試行團隊，足以支援任一市場，但不能同時支援兩個。現有客戶承諾、法定工時要求及儲備均不受影響。公司的目標是在維持相同服務標準的前提下，扣除所有因市場而異的試行成本後，取得較高的邊際貢獻。沒有額外的策略價值估算顯示哪個市場較有利。

試行計劃的完整差旅報價為 N 12,000港元、F 36,000港元，已涵蓋所有必要行程及相關的有薪交通時間。N 地理上較近，出差費用也較低。至於為兩組客戶提供服務還需要作哪些調整，團隊尚未收到整合資料。

兩個虛構方案的合法服務供應、入境、資料處理及稅務安排均已分別核查；相關成本凡有差異，均已列入即將提供的資料。不能因地理位置接近，就假定已取得許可或專業資格獲得承認。沒有合約已簽訂，也沒有客戶在等候公司承諾的服務推出日期。

你的決定

你會單憑差旅成本選擇 N，還是暫時保留兩個選項？就這項服務而言，你會核實哪些營運差異？請說明每項差異可能如何影響成本或可行性，不要依賴對國籍的刻板印象。

第二輪 · 多了一項資料

資料把客戶要求與政府規定分開。N 的客戶群要求按其供應商標準，付費評核團隊的培訓紀錄，費用為30,000港元。F 的客戶群接受團隊現有的資格證明，核實費用為6,000港元。兩個方案均可在服務推出前完成有關程序。這些是商業上的接納程序，並非法定牌照審批，也不代表資格在國際間自動獲承認。

N 的客戶要求採購文件和工作坊材料使用團隊目前未能支援的語言。由合資格人士翻譯及主持工作坊，費用為24,000港元。F 的指定客戶使用團隊現有的工作語言，毋須額外支付翻譯費。這些已核實的偏好只適用於這些客戶，並不代表任一城市的所有居民。

為配合 N 客戶的匯報流程，調整和測試需18,000港元；配合 F 客戶則需8,000港元。兩項調整均不影響服務質素或資料保障。N 議定的付款時間表帶來6,000港元的額外融資成本；F 按階段目標付款，不產生額外融資成本。以上是完整報價，不是未付發票的結欠，也不是按國籍對付款誠信所作的假設。

計及差旅，兩地各自須計入的試行成本為：N：12,000 + 30,000 + 24,000 + 18,000 + 6,000；F：36,000 + 6,000 + 0 + 8,000 + 0。每項費用只計一次，而且都不包括在計算180,000港元情景邊際貢獻時已扣除的成本內。

兩個完整方案均在預算之內，也不超出團隊已獲撥款可承擔的工作量，包括評核、翻譯和測試。兩地客戶均未就六個項目簽約。需求仍有同樣的不確定性，公司也可以不推行試行計劃。所有要求和報價只適用於指定客戶群及試行期。

你的決定

按既定目標，你會優先選擇哪個城市？請比較兩地各自須計入的成本總額及情景下的邊際貢獻，再列明作出承諾前須核實的事項。說明為甚麼你的結論既不是「近就容易做」，也不是「較遠的市場更好」。

講評 · 計算配合營運要求的全部成本

N 的總成本為90,000港元，F 為50,000港元。N 的差旅成本少24,000港元，但其餘列明的調整多花64,000港元：N 為78,000港元，F 為14,000港元。兩相抵銷後，N 的成本仍高出40,000港元。

扣除這些成本後，在條件一致的情景下，N 的邊際貢獻餘下90,000港元，F 則餘下130,000港元。按既定目標，應優先考慮 F，但仍須視乎客戶是否作出承諾，以及各項準備是否就緒。這是對試行計劃所帶來的額外收支作比較，並非全公司的利潤、有保證的銷售額，或任一市場在整個經營期的估值。

講評 · 把差異化為具體工作

在本個案中，地理距離影響出差安排及有薪交通時間。客戶的供應商評核程序影響取得客戶接納所需的工作；語言影響材料編製及工作坊主持；匯報做法影響實施工作；付款時間則影響融資。真正要問的是：為了服務這些客戶，FrameDesk 有哪些工作要改用不同做法，又要投放甚麼資源？

文化、行政、地理及經濟距離是有用的分析角度，並非四項通用評分。客戶使用的語言不能代表整個文化；私人機構核實資格，也不等於國家設有牌照障礙。有些差異橫跨不同類別。每項實際工作只應計算一次成本，不要再就同一項工作加計一筆「距離成本」。

講評 · 先確認必要條件，再比較優次

如果公司無法合法提供服務，或達不到必須符合的標準，即使某個市場成本較低，也不能選擇。本個案中，兩個方案都有可行且已獲撥款的合規及籌備安排。這項假設讓我們可以比較成本，但不代表購買翻譯服務或通過客戶評核，就會自動取得所有法定許可。

作出承諾前，應向有關負責方核實適用的現行規定、評核是否完成、材料是否通過測試、資料處理安排、客戶接納的交付成果及付款條款。文件應繼續清楚區分法定許可、專業能力及特定買家的接納，三者不能互相替代。

講評 · 需求須另行考慮

六個項目的情景讓兩地營運成本可以直接比較；通過審查不等於取得六張訂單。在招致市場進入成本前，應確認實際工作範圍、價格、交付日期，以及由獲授權人士作出的採購承諾。若兩組客戶的需求或邊際貢獻有異，便應重新計算，而不是假定 F 仍然優先。

按所列成本，N 在扣除市場進入成本前的邊際貢獻須比 F 多40,000港元，最終邊際貢獻才會打和。在其他條件不變下，差額超過40,000港元，優次便會逆轉。這是敏感度分析的臨界點，並非預測會有額外需求或可以收取較高價格。

講評 · 有選擇地沿用現有能力

雖然路程較遠，F 的客戶要求與這支團隊現有的工作語言、資格和匯報方式更配合。另一家能力不同的出口企業，所需的營運調整可能恰好相反。距離要視乎服務、企業和選定的客戶而定，不只是地圖上某個地點本身的特徵。

試行後，應檢視實際交付所需的工夫、客戶是否接納、付款時間及有沒有後續需求。進入市場所做的工作可能建立日後可再用的能力，但本個案沒有估算其未來價值。N 仍可留待日後考慮；這次不選 N，並非對當地居民或市場長遠潛力作出判斷。

STR-04 為選定渠道作產品調適；STR-15 比較密集與分散的分店網絡。本個案的目的地仍有待選定，而多項營運差異推翻了只按地理遠近得出的排序。所有城市、客戶、要求及成本均屬虛構。來源提供分析框架和一般出口指引，並非就特定司法管轄區提供現行法律意見。
