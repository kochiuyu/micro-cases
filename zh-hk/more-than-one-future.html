STR-08 · 香港 · 10–15 分鐘 · 策略 · 情景規劃 · 策略靈活性

一個預測，三種策略？

新聞裏 · 為不止一種未來作規劃

2025年5月15日，香港交易及結算所有限公司舉辦了一場 ESG學院研討會，探討氣候策略、情景規劃及分析。其公開上載的簡報指出，探討多種合理可想像的未來情景，與預測單一未來有別，並說明這種思路如何影響策略選擇。

這個虛構個案把上述一般思路應用於客戶的採購模式，而非氣候匯報。研討會並無討論這家培訓機構，也沒有認可這些虛構數字。

課堂決定

虛構的課堂情境。 一家提供商務簡報技巧培訓的香港機構，正為來年選定服務開發重點。機構只會選一個重點，不會把兩種服務各自全面開發。只要提供適切的學員支援，機構的合資格導師可以教授任一方案的課程。

A: 為統籌培訓的企業團隊開發具特色的完整班組課程。 B: 開發可獨立修讀的短單元，供有特定培訓需要的部門經理選購。要決定的是提供甚麼服務、賣給哪些客戶，而不是短課程的教學成效能否媲美長課程。

兩個方案都負擔得起，即使出現所列的不利結果亦然。未有客戶作出承諾，也沒有概率估算顯示哪個情景較可能出現。經理希望選擇能配合機構日後可能遇到的客戶採購模式的策略。

以下是同一個來年的兩個對照情景，供課堂討論： 集中採購課程：客戶把培訓採購集中起來，購買較全面的班組課程；以及 部門自行選購：培訓預算仍然可用，但各部門按需要購買較小的單元。這些情景不是預測，沒有假定兩者出現的機會相同，也沒有涵蓋所有可能的未來。

新服務 · HK$000集中採購課程部門自行選購
A · 完整班組課程300−60
B · 獨立單元目錄100180

表內各項均為虛構的一年新增現金盈餘，已扣除開發、推廣及提供服務所涉及的全部新增現金成本。不變的現有業務不計在內，這項簡化比較也不考慮融資和稅務影響。因此，−60 代表這項計劃虧損60,000港元，不一定代表整家機構錄得虧損。

你的決定

你會暫時選擇 A 還是 B？說明哪個客戶採購情景最影響你的選擇，以及甚麼證據會令你重新考慮。

第二輪 · 改了一個事實

導師完成了一項有償的課程設計可行性研究。核心練習可以設計成可重用的單元，既可獨立出售，也可配合經專門設計、由導師帶領的開場、綜合總結和後續跟進，組成連貫的班組課程。

這樣一來，在作出承諾之前，便有第三個可行方案： C：以模組化單元為核心，配合導師引導組合成課程。單元次序、評核和學員支援仍須設計。估算已計及額外的架構設計和調適工作，以及推廣和提供服務的成本；靈活性並非沒有代價。三個方案仍然都負擔得起。

一年新增現金盈餘 · HK$000集中採購課程部門自行選購
A · 完整班組課程300−60
B · 獨立單元目錄100180
C · 模組化核心，配合導師引導組成課程220140

沿用相同的現金成本計算基準及不計入的項目。C 的整合成本較高，服務也較少針對特定需要，因而限制了收益上行空間。設計可行不等於有客戶需求，也不能證明學習成效相同或保證收到款項。

你的決定

現在選擇 A、B 或 C。你願意放棄哪些較高收益的機會？你會在觀察到哪個客戶訊號時檢討選擇？

檢驗服務方案，不只看自己偏好的情景

A 適合希望提供較全面班組學習體驗的集中採購客戶；B 適合購買較小獨立單元的部門。每個方案都要放在兩個客戶採購情景下檢視，不能只看最有利於該方案的情景。

個案沒有提供概率。把兩欄取平均，就等於在沒有說明的情況下假設兩者權重相同。如果策略上優先發展集中採購的課程，而且能承受所列的虧損，選 A 有其理據；如果着眼於部門需求，或重視 B 在其較弱的所列情景下仍有較佳表現，選 B 也有其理據。

算清靈活性的代價，不要假設它是免費的

在集中採購課程的情景下，C 比 A 少80,000港元；在部門自行選購的情景下，C 比 B 少40,000港元。C 在兩欄都不是表現最好的方案。

在表列的兩個情景中，C 較低的結果是140,000港元，B 是100,000港元，A 是−60,000港元。如果經理重視方案在這兩種不同情況下的表現，並願意為此放棄專門方案的較高收益潛力，C 就有吸引力。這並不證明 C 是所有人的最佳選擇。

不要把情景表的結論推及表外

140,000港元是 C 在這張表內的最低結果，不是有保證的現金下限，也不是所有情況下的最壞結果。其他客戶採購模式、競爭對手的行動或提供服務時遇到的困難，都可能帶來更差的結果。這些數字是用作策略比較的假設，不是經核實的香港需求預測。

可行性研究帶來一個真正可選的方案，但沒有證明買家想要這項服務。只要說明策略理據和對各種結果的承受程度，選 A、B 或 C 均可。個案沒有提供按期望值排列的次序。

把策略與觸發檢討的訊號連起來

指定一名檢討負責人，每月查視符合條件的查詢和實際採購承諾：要求整套課程的客戶是否愈來愈多，還是選購獨立單元的客戶愈來愈多？同時查看查詢轉為訂單的情況和授課反饋，不要把每宗查詢都當作一宗成交。

先議定甚麼持續趨勢會觸發檢討、它會挑戰哪項假設，以及屆時會考慮如何應對。一宗不尋常的要求，不代表出現了新的未來情景。日後更改服務仍可能需要時間和開支；C 並不能免除所有調適成本。

教師說明

介紹 C 之前，先讓學生在 A 和 B 之間作暫定投票。請學生說出選擇背後對客戶採購模式的假設，而不是猜測有沒有一個隱藏的正確概率。兩個情景都有培訓預算；不確定的是客戶如何購買培訓服務，而不只是經濟好壞。

揭示新資料後，請學生說明 C 能保住甚麼，又要犧牲甚麼。表列最低結果為 −60、100 和 140（HK$000）。不要把 140 說成有保證的下限，也不要指定應採取哪種風險取態，或在沒有明確提出新假設的情況下採用等權重平均。

所有方案都可行，亦有足夠資金推行。個案討論的是服務開發策略，不是課室容量、現金收支時間或投資回收，也不是要對教學成效作出判斷。這項為期一年的課堂壓力測試刻意簡化，有別於參考資料中較完整、往往涵蓋更長時段的機構情景分析方法。
