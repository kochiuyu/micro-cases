ENT-37 · 新加坡 · 15–20分鐘 · 受監管業務設計 · 預期用途 · 證據與現金可維持期

示範成功，走完監管途徑卻需時更長

用途聲稱如何左右業務設計

完成感測器示範、以臨床證據支持診斷用途聲稱，以及能夠交付研究工具，是不同的商業階段目標。新加坡衞生科學局（HSA）規定，經指定途徑供應非臨床產品須獲批准；「研究用途」並非一概豁免。醫療科技開發計劃把工程、品質、臨床、監管及商業工作結合起來，而不是把取得批准視為最後一道宣傳工序。

課堂決定

新加坡的虛構企業 SignalSpring 有一部實驗台式感測器，能在合成參考材料上取得可重複的讀數。整個過程不涉及病人樣本、病人紀錄或診斷決定。示範只證實了這項範圍有限的技術結果。創辦人必須選擇一條開發路線，因為資金不足以同時推行兩條路線。

C 路線最終要支持一項面向醫療機構買家的特定臨床診斷用途聲稱。在作臨床用途供應之前，必須有與聲稱相稱的證據、品質管控措施，並取得所有適用的許可。目前既未取得任何批准，也未證實臨床表現。團隊的初步商業試算表假設第4個月便可開始收款，但這個時間尚未核實。

R 路線擬供應一款用途明確受限的實驗室工具，只供使用合成參考材料進行實驗，不涉及人體測試、診斷、病人管理或臨床判讀。個案只就這條虛構路線設定：在上述確切範圍內，所需許可已取得，亦已由合資格人士完成審查。這些許可和審查不涵蓋 C 路線，也不涵蓋客戶的臨床用途。

企業已另行預留資金，以履行所有現有義務，並全額備妥有序停止營運所需的款項；扣除這些受保障款項後，仍有 S$240,000 可動用。兩條路線的核心人員、設施及品質管理成本均為每月 S$20,000。C 在起步時另需 S$60,000，R 則需 S$40,000。這些是個案設定的全部現金成本，並非監管機構收取的費用。

初步試算表假設，自第4個月起，C 和 R 每月的客戶淨現金貢獻分別為 S$25,000 和 S$10,000。這裏的貢獻，是客戶付款扣除為該客戶交付和提供支援的一切現金成本後的款額，尚未扣除另計的每月核心成本。金額及收款時間均未獲任何買家確認。

董事會眼前的目標，是選擇一條範圍界定得宜的路線，在不取得新資金、也不動用受保障的結業準備金下，營運至第12個月底。目前沒有可用的貸款、資助或投資者承諾。比較時要看用途範圍、證據及現金收付時間，不能只看哪條路線的預計貢獻較高；目前並無任何銷售承諾。

你的決定

C 的預計貢獻較高，是否足以支持現在就把可動用資金投放到這條路線？指出這次示範仍未證實甚麼，並說明每位買家的預期用途、所需證據和首次付款日期各有哪些事項必須核實。

第二輪 · 多了一項資料

C 的潛在買家確認，需要的是能提供診斷判讀、供病人相關決定參考的設備，而不是只供研究使用的讀取儀器。在有適當證據並取得全部所需許可之前，買家不會付款。合資格人士就開發所作的評估指出，最早也要到第18個月底才有可能準備就緒，而且仍可能延誤。這是虛構的項目估算，並非 HSA 對審批時間的承諾。

R 的研究買家確認，用途嚴格限於以合成材料進行非臨床實驗，並提供已有資金支持的付款時間表。僅就本練習而言，從第4個月至第12個月，包括首尾兩個月，每個月月底均收到 S$10,000 淨現金貢獻。這筆款項已扣除交付成本，並在當月核心成本支付前到賬；沒有訂金或其他收入。

R 的使用說明、示範、支援及客戶驗收均須限於非臨床用途。團隊不能以 R 滿足 C 買家的診斷需求，也不能在涉及病人使用的聲稱旁加上「研究用途」標示便算數。預期用途如有任何改變，必須先由合資格人士重新評估監管要求及所需證據，才可作出承諾；不能擴大個案所設定的許可範圍。

C 路線在首十八個月不會收到任何臨床用途款項；即使在第18個月準備就緒，也不保證獲批或有銷售。核心成本仍須每月支付，C 的起步成本也不能省卻。個案沒有假設 R 在第12個月後仍有款項收取。擬定的付款時間表不能證明會續約、會增長或能長期盈利。

你的決定

哪條路線符合董事會的十二個月資金要求？計算兩條路線各自的現金狀況，以及 C 營運至第18個月底的最低資金缺口。解釋為甚麼 R 即使能帶來較低的現金貢獻，也不能證實 C 的臨床診斷用途聲稱，或保證業務可以持續。

講評 · 示範證實的能力較有限

在合成材料上取得可重複的讀數，並不能證實感測器在目標病人群組中的診斷表現。C 須明確界定臨床用途，取得支持該用途的證據及相關許可。買家有興趣不等於已獲批准。R 處理的是另一項研究工作，而買家已明確接受其限制。

開首的試算表只能視作初步估算。買家在完成規定程序前不會付款，因此表內 C 的 S$25,000 並不是可動用的現金。不要把第4個月的研究用途收款，與毫無依據的第4個月臨床用途收款相比，當作兩筆款項都可動用。

講評 · C 尚未準備就緒便耗盡資金

C 支付起步開支後，餘下 S$240,000 − S$60,000 = S$180,000。在沒有款項收取的情況下，每月開支為 S$20,000，這筆錢可維持九個月。到第9個月底，現金便告用盡，未到第12個月的檢視點，也遠早於估算中最早可準備就緒的時間。要進入第10個月繼續營運，就需要新資金。

維持十二個月需要 S$60,000 + 12 × S$20,000 = S$300,000，資金缺口為 S$60,000。維持十八個月需要 S$420,000，相對可動用資金，缺口至少為 S$180,000。這只是維持至最早可能準備就緒的時間所需的資金，並非涵蓋直至獲批或取得商業成果的完整預算；任何延誤或額外要求都須另籌資金。

講評 · R 的現金足以撐到檢視點

R 支付 S$40,000 起步成本後，餘下 S$200,000。扣除首三個月的核心成本後，首次收款前的現金結餘為 S$140,000。第4–12個月共收款九次，合計 S$90,000。十二個月的核心成本合共 S$240,000，因此期末現金結餘為 S$240,000 − S$40,000 − S$240,000 + S$90,000 = S$50,000。

第3個月過後，現金每月減少 S$20,000 − S$10,000 = S$10,000。現金結餘全期不低於零，最後的 S$50,000 是按此時間表計算的最低結餘。R 無須動用受保障資金，便符合董事會在檢視點的要求。這個結論以個案設定的款項如期到賬、成本全數計入為前提。

講評 · 要選的是商業模式，不是標籤

就這項十二個月的目標，應選擇用途範圍明確受限的 R。待有可信的臨床開發計劃，並取得足夠的資金承諾，再考慮 C；不要向買家承諾推出臨床產品。這並不表示 C 已被證明毫無商業價值，而是其目前的融資及取證途徑不符合這次決定的限制。

R 開始收款後，每月仍淨耗用 S$10,000。若這個收支模式持續，S$50,000 也只夠多維持五個月；但個案沒有提供續約款項，因此連這段延長期也只是假設。到檢視點仍有現金，不等於有盈利，也不證明這名買家以外另有市場需求，更不代表可以不付代價地為 C 提供資金。

講評 · 讓用途聲稱與實際交付一致

以文件記錄獲准進行的研究工作、各方接受的性能限度、客戶須遵守的限制及支援範圍。如有人要求提供臨床判讀，應先查明情況，不應私下照辦。單憑「研究用途」的字眼，不能把原定用於診斷的產品變成不受限制的工具。實際分類及所需許可，須由合資格人士按相關司法管轄區的現行要求評估。

世界衞生組織及國際證據指引說明，分析測量與臨床表現是兩回事。相關計劃並不自動適用於這部虛構裝置，也不會賦予新加坡的批准或證明裝置安全。本課堂練習並不授權進行任何涉及人體的研究、作出健康聲稱、進行試驗或進行醫療器械交易。

來源與個案假設 · 選讀

課堂決策所需的資料，上文已經齊備。來源只供選讀，用來交代出處和背景。

原創虛構個案，不涉及臨床使用或實際監管裁定。R 只使用合成參考材料，不涉及人體樣本、人體資料或對病人資料作判讀。個案設定 R 已在確切用途範圍內取得所需許可，並由合資格人士完成審查；這並非研究用途一概豁免，也不是安全認證。C 未獲批准，也沒有臨床證據；最早18個月才準備就緒是虛構的時間下限，並非監管機構的處理時間，也不保證獲批。另行預留履行義務及有序停止營運的受保障款項後，可動用資金為240000；每月核心成本全數為20000，起步成本為 C 60000、R 40000。初步假設自第4個月起每月貢獻為 C 25000、R 10000，尚未核實。第二輪揭示 C 直至第18個月底均無收入；R 在第4–12個月每月有10000淨現金貢獻，在支付核心成本前到賬，已扣除所有個別客戶成本。C 的現金可維持9個月，第12個月的資金缺口為60000，第18個月的最低缺口為180000。R 在第3個月底的現金為140000，收款9次共90000，第12個月底現金為50000，第3個月後每月淨耗用10000。沒有新資金、貸款、資助或額外人手，不會同時走兩條路線，也不假設第12個月後會續約。檢視點衡量的是資金是否足夠，而非盈利能力。各來源所述的監管範圍有別；不把 FDA、WHO 或 GHTF 的程序當作新加坡法律。

  1. Singapore HSA · Import and supply of unregistered medical devices for non-clinical purposes。現行本地指引規定，經指定途徑供應非臨床產品須獲批准，並對供應範圍設有限制。指引明言，審理這類申請時不會評估安全及性能；本個案不把取得許可視為產品已獲驗證。

  3. US FDA · Distribution of In Vitro Diagnostic Products Labeled for Research Use Only or Investigational Use Only · 2013。原指引說明，除了標籤，為甚麼預期用途、市場推廣和支援也很重要。美國的規定只供背景閱讀，並非新加坡法律，也不構成供應這部裝置的許可。
  4. GHTF Study Group 5 · Clinical Evidence for IVD Medical Devices: Key Definitions and Concepts · 2012。這份較早期的最終版技術框架區分分析性能、臨床表現與預期用途。它既不是現行的審批核對清單，也不是說一項研究便足以證明臨床效用。
  5. WHO · In Vitro Diagnostics: Performance Evaluation。世界衞生組織說明，如何按指定規程，從分析特性及臨床特性兩方面對合資格產品作獨立評估。本個案不假設其計劃適用於這部虛構感測器，而世界衞生組織的評估也不等於新加坡的許可。
