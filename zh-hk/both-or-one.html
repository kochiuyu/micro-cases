推出套餐，人人都要兩項一起買嗎？

新聞裏 · 有得選的套餐

2025年7月3日，香港旺角帝盛酒店宣傳一款住宿套餐，讓住客自選三項禮遇，選項包括交通和餐飲。

這則過往的公司公告，讓我們思考服務可以怎樣組合，又可以給顧客哪些選擇。酒店的方案與本個案虛構工作室的方案不同；公告既不是收入增加的證據，也沒有說明酒店目前是否仍提供該套餐。

課堂決定

虛構的課堂情境。 香港一間手作工作室在不同時段開辦筆刷字藝班和摺紙班。兩項課堂各有用處，顧客可以只上一項，也可以兩項都上。各方案的課堂品質相同，名額充足，現有員工及場地成本亦相同。

每位顧客每上一項課堂，材料成本為20港元；兩項都上則為40港元。合售不會節省成本。本練習不設額外預訂或方案成本，不涉及稅項、退款或時段衝突，課堂亦不可轉讓、轉售或重複購買。

起初只有顧客 A 和顧客 B 各一名。下表的估值是為個案虛構的最高願付價格，並非調查結果。估值已計及時間和精力，兩人的預算均充足。各人會從可選的購買方案中，找出最高且不低於零的 「估值減總價」差額。甚麼都不買，所得為零。

分開出售： 每項課堂90港元，兩項共180港元。 只售套餐： 兩項合售125港元，不設單購。套餐的估值只是兩項課堂的估值之和，沒有額外價值。

比較邊際貢獻，即銷售收入減去增量材料成本，而非工作室計及所有成本後的利潤。顧客會出席所選的課堂。按這些價格計算，不會出現選項得益相同的情況。

你的決定

你暫時會向這兩名顧客提供哪個方案？指出他們各自會怎樣選擇，並比較買家得益和工作室的邊際貢獻。哪一類顧客可能令你改變選擇？

第二輪 · 改了一個事實

方案公布前，預訂統籌員加入了 顧客 C，其筆刷字藝課堂的估值為100港元，摺紙課堂的估值為零。現在練習中只有 A、B、C 各一名，這並非對各類顧客所佔比例的預測。

預訂系統毋須增加行政成本，便可提供第三個方案：兩項課堂仍可各以90港元單購，同時提供125港元的兩項套餐。這就是 混合捆綁。除此之外，價格、品質、材料成本、名額和時段均維持不變；沒有隱藏收費，也不會自動加購。

用同樣這三名買家比較三個候選方案。各人仍會選擇估值減價格後差額最大的選項，而不是隨便選一個有正得益的購買選項。

你的決定

面對這三名顧客，你會只售單項課堂、只售套餐，還是採用混合方案？算出他們實際會怎樣選擇，並指出正式推出前，你會驗證哪一項有關實際成本或需求的假設。

對最初兩名買家而言，套餐有可取之處

分開出售時，A 選筆刷字藝，B 選摺紙。每人的買家得益為100港元 − 90港元 = 10港元。收入為180港元，材料成本為40港元，邊際貢獻為140港元。

只售套餐時，兩人都買下兩項課堂。每人的得益為140港元 − 125港元 = 15港元。收入為250港元，但四個課堂名額的材料成本為80港元，邊際貢獻為170港元。

在這個只有兩名買家的模型中，邊際貢獻增加30港元，買家合計得益增加10港元。成本亦有上升；套餐既沒有創造額外價值，也沒有降低材料成本。

用同樣三名顧客重新比較各方案

只售單項： A 和 C 選筆刷字藝，B 選摺紙。收入270港元 − 材料成本60港元 = 邊際貢獻210港元。每名買家得益10港元，合計30港元。

只售套餐： A 和 B 選套餐；C 甚麼都不買，因為100港元 − 125港元是負數。收入250港元 − 材料成本80港元 = 邊際貢獻170港元。買家總得益為30港元。

混合方案： A 和 B 選套餐，C 選筆刷字藝。收入340港元 − 材料成本100港元 = 邊際貢獻240港元。買家各自的得益為15港元、15港元和10港元，合計40港元。

按題設假設，混合方案在這三個候選方案中帶來最高的邊際貢獻。不要拿最初兩名買家的總額與後來三名買家的總額相比，再把差額歸因於方案。

要預測買家怎樣選，不只看他們是否負擔得起

在混合方案下，A 和 B 買套餐可得15港元，高於各自最喜歡的單項課堂所帶來的10港元，所以兩人都偏好套餐。對 C 來說，單購筆刷字藝可得10港元，勝過買套餐所得的−25港元，也勝過甚麼都不買。

單購選項讓 C 也能參加，同時保留 A 和 B 偏好的套餐。即使買家負擔得起兩項課堂，也不一定會選內容最多的套餐，還要看有哪些其他選擇。

別把模型的結果推得太遠

這裏只比較三個候選方案，並未證明這些是最好的價格。估值或材料成本不同、課堂名額有限，或涉及額外行政工作，都可能改變結果。這裏為教學而列出確切的願付價格，工作室平時並不能直接知道這些數字。

確保顧客確實可以單購，並清楚列明總價、所包課堂、上課時間及條件。本例不能證明所有套餐都惠及所有消費者，也不能解答競爭法問題。

教師說明

第一次投票時，只讓學生看到 A 和 B；然後才加入 C 和可行的混合方案。要求學生先找出每名買家得益最高的購買選項，再加總收入。兩項服務的估值可以直接相加，並未假設一起使用會因互補而產生額外價值。

揭曉後，所有比較都用同樣三名買家。按這些價格，混合方案的邊際貢獻比只售單項高30港元，比只售套餐高70港元；這些數字並非香港市場的估算。邊際貢獻不計維持不變的員工及場地成本，因此這裏沒有提供計及所有成本後的利潤。

可另作一道檢核題：如果混合方案的套餐改為135港元，而單項仍為90港元，結果會怎樣？A 和 B 會選各自最喜歡的單項課堂，因為得益為10港元，高於套餐的5港元。這是另一個情境，並非修改個案原定價格。競爭對手的行為、全行業的福利及法律評估均不在本模型的範圍內。
