最好的項目。最好的一組項目？

一筆投資，仍然要單獨論證

2024年十二月13日，香港宣佈，科技券計劃在2024年十二月31日之後停止接受申請。這個計劃曾經支持各行各業採用科技。這個帶日期的變化，只是回頭看投資資金時的背景，不能證明任何一間公司失去了已經答應的資助。下面的企業和項目選擇都是原創虛構，並且假設沒有補貼。

課堂決定

一間虛構的香港文具批發商，今天有100,000港元可以用於自行決定的改進。這是這一輪經董事會批准的固定投資額度，不能拿來證明公司已經無力償債。現有經營、必須完成的安全和私隱工作、工資，以及已經承諾的客戶服務，另有受保護的資金。在這次決定裏，沒有額外的借款、補貼，也不能把別的預算調過來。

三個項目都已經準備好。每一個都不可分割：要麼撥付全部支出，要麼不要開工。它們可以一起運作，沒有重疊，也沒有資源衝突；在最初的比較裏，淨現值可以相加。目前還沒有任何工作已經承諾下去。附表裏的數字，單位都是000港元。

所給的淨現值，已經扣掉初始支出，也扣掉了同一規劃期內、按同一套風險調整後的折現基礎計算的全部相關經營、培訓、支持、稅和營運資金現金流。它們是覆核過的估計，不是會計利潤，也不是今天已經到手的現金。以後沒有還未備妥資金的資本開支。目標是在這個固定額度裏取得最大的淨現值合計；按這個基礎，沒花掉的現金，增量淨現值是零。

你的決定

這100,000港元，你會撥給哪個可行的項目，或哪一種組合？請說明：為甚麼單獨淨現值最高、或者每元支出的淨現值最高的那個項目，不一定就是整個預算下最好的結果。

第二輪 · 多了一項資料

任何一個項目還未批准之前，團隊提出第四個不可分割的選項：D，一個報表模組。它的全部初始支出是30,000港元，單獨來看的淨現值是3,000港元。D可以自己運作，也可以和任何一個其他項目一起運作。它的時間、風險基礎和全壽命成本，都和前面的選項一致。

一份獨立的內部覆核確認，A和D可以兼容，並且只有兩個都實施時，才支持額外20,000港元的模型淨現值。這是它們各自淨現值之外的相互作用，已經扣掉全部整合、培訓和持續支持的成本；除了已經寫明的支出，不需要再付一筆初始現金。這項好處還沒有算進A，也沒有算進D。其他任何一對都沒有相互作用。成本、預算和原有的基準義務都沒有變。

把這20,000港元當作本練習給出的、已經覆核的預測，不是有保證的協同，也不是供應商拿不出依據的承諾。還沒有發生任何採購。東主仍然可以改選最初的那一組，並且想看看：相互作用的價值小到甚麼地步，建議就會反過來。

你的決定

項目D和這份覆核過的相互作用都擺出來了。你現在會選哪一組？請寫出它的總支出和淨現值，並指出額外的相互作用價值要小到甚麼程度，你的建議才會改。

比較可行的組合，不要只排名次

A的單獨淨現值最高：35,000港元。按每元支出計算的淨現值也最高：35 / 70 = 0.50，B或C則是24 / 50 = 0.48。可是A只剩下30,000，剩下的兩個初始項目哪一個都不夠做。B加C用掉100,000港元，淨現值加起來是48,000港元，超過單獨做A。A再加B或C要花120,000港元，做不到。

一項互補，會改掉整組

A加D用掉70,000港元 + 30,000港元 = 100,000港元。淨現值合計是35,000港元 + 3,000港元 + 20,000港元 = 58,000，勝過B加C的48,000港元。B加D，或者C加D，花費80,000港元，得到27,000港元。任何三個項目湊在一起，都超出預算。最好的可行組合變了，是因為多了這個選項，以及它那個劃定範圍內的相互作用，不是因為A原來的淨現值算錯了。

要檢驗相互作用，而不是為它叫好

如果沒有相互作用，A加D得到38,000，低於B加C。設額外的相互作用為x，打和的式子是38,000港元 + x = 48,000，所以x = 10,000港元。高於這個數，按這些假設選A加D；低於它，選B加C；剛好相等，模型認為沒有差別。承諾之前，先核實整合做得到、好處有人負責、事後有人監測。同一筆節省，不要數兩次。

教師說明

FIN-08比較的是兩筆互斥的房間投資，時間不一樣。這裏的項目可以放在一起做，但金額是一整塊，預算是固定的，目標是最好的那一組。簡單按比率排隊，解決不了這種不可分割的問題。我們這裏明確用淨現值除以支出。有的教材把盈利能力指數定義成現金流入的現值除以支出，在這個簡單情形裏會再加一。兩種算法都不要和會計上的投資回報率混在一起。後面的相互作用是一條預測假設，不是實證證明，也不能當成突破受保護預算的理由。

  4. HM Treasury: Green Book 2026。實際的評估指引討論了依賴關係和約束。公共部門的社會價值指引，不是私人淨現值的硬性要求，它的折現率也沒有被引進來。
  5. UK Government: Gate Review 5, benefits realisation。討論相互依賴、好處的管理、風險和資金保證。這是管治研究的一條線索，不能當成虛構的相互作用一定會發生的證據。
