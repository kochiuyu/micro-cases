投資者帶來客戶，但我們可以服務哪些客戶？

不只是一張支票

企業創投既可提供資金，也可讓初創企業接觸業界，但同時會把初創企業與投資者的商業重點連繫起來。比較方案時，不能只看眼前的投資額，還要看企業日後可銷售甚麼、可披露哪些資料，以及可如何融資。

下文的新加坡初創企業、投資者及條款均屬虛構。文中並不表示任何條款屬標準條款、可強制執行，或適合作為法律條文。

課堂決定

你是新加坡軟件初創企業 RouteLedger 的共同創辦人。公司向物流營運商銷售配送例外情況報告工具。你現在要選擇的是規劃方向，而不是簽署文件。獨立投資者 I 和企業投資者 C 各出價 S$1,000,000，換取投資後 20% 的普通股股權。除下文列明的差異外，其他經濟及管治條款均相同。

兩筆投資都足以全數支付同一項為期六個月的產品及銷售試點所需開支。必要承諾及創辦人的生活開支另有保障，因此拒絕或押後決定都可行。任何最終安排均須通過獨立的法律及競爭事宜審查，方可接受。這項課堂練習不涉及任何交易、敏感資料披露或權限變更。

I 不會增設客戶限制，也不會就未來投資者的身分保留否決權。I 每季收取財務及營運匯總報告，但不會引薦客戶。C 的母公司是物流營運商；C 另承諾在交割後八星期內，與其商業人脈中的聯絡對象安排四場經對方同意的客戶探索會面。

C 引薦的是會面機會，並非採購承諾或背書。RouteLedger 仍須確認客戶需求是否切合產品、議定商業條款，並爭取成交。C 建議的限制在交割後維持 12 個月：RouteLedger 不得向四家指定的物流營運商 N1–N4 授權使用其報告軟件。名單不會自動擴大，其他客戶均不受限制。

在同一段 12 個月期間內，接受 N1–N4 的股權投資前，須先取得 C 同意。C 對其他投資者沒有額外否決權。兩份方案均無承諾提供後續資金，也不包含出售公司時的優先權、收購選擇權，或按另一名投資者的出價作同價出價的權利。

除匯總報告外，C 每季亦會收到產品開發路線圖，內容僅限功能主題和預計推出時段。在保密及內部分隔條款下，只有 C 的投資團隊可查閱。所提供的資料不包括源碼、列明名稱的潛在客戶名單、客戶紀錄或客戶機密資料。現有客戶許可及發放管控維持不變。

你的決定

你會暫時傾向哪個方案：I、C，還是押後決定？把對方承諾提供的資源，與你會失去的商業選擇和須讓步的資料披露界線作比較。哪些客戶方面的證據可能令你改變決定？

第二輪 · 多了一項資料

團隊現查核四家經評估後最具潛力的準客戶。其中三家是 N1、N2 和 N3，均在 C 的限制名單上；第四家不受限制。這些都是準客戶，並非訂單。與目前已篩選的其他銷售線索相比，這幾家更切合擬推出的產品，但個案沒有提供轉化概率、利潤率或客戶價值。

C 提出一份書面備選方案供規劃之用，稱為 C-narrow：出資 S$900,000，換取同樣的 20% 股權。這個方案的軟件授權限制只適用於 N1 和 N4，為期僅六個月。N2 和 N3 即時不再受限。C 的其餘條款維持不變，包括四場會面、產品開發路線圖資料，以及為期 12 個月、對接受 N1–N4 投資的同意權。

S$900,000 仍足以全數支付原定六個月試點的開支，涵蓋所有員工工時及支援。I 或 C 原方案多出的 S$100,000 會留作未有指定用途的現金緩衝，並非未列明的必要開支。採用 C-narrow，毋須無償補足資金、假定會收到銷售款項，或降低交付標準。

三個方案仍可審視，尚未接受任何一個。C-narrow 的客戶限制在六個月後屆滿，不會自動續期。準客戶不受限制，並不代表願意向有企業投資者支持的供應商採購。沒有客戶承諾會接受這層關係或成為投資者。

你的決定

根據這些資料，在 I、C、C-narrow 和押後決定之間作出選擇。指出哪些經評估的準客戶仍不受限、收窄 C 的客戶限制明確要付出甚麼代價，以及 C-narrow 沒有解除哪些限制。

講評 · 資金換來一段關係

選擇 I，可保留接觸全部四家經評估準客戶的機會，不受額外商業限制。選擇 C 原方案，則在 12 個月內只有原本不受限的那家準客戶仍可成為客戶。作為交換，C 提供的是四場由其安排的客戶探索會面及接觸業界的機會，而不是四家付費客戶。把這些具體資源與限制會排除的機會作比較。

講評 · 限制收窄，但有代價

在 C-narrow 下，N2、N3 和原本不受限的準客戶即時可成為客戶；N1 仍受限六個月。投資者取得同樣的股權，但提供的現金少 S$100,000。這是現金緩衝實際減少，並非同一筆費用付了兩次，也不代表試點的資金未有着落。限制只是收窄，並未消失。

講評 · 細看仍然適用的條款

在整段 12 個月期間內，C-narrow 仍規定接受 N1–N4 任何一家的股權投資前須取得同意，即使該公司較早已可成為客戶，規定亦然。提交產品開發路線圖的要求亦維持不變。接觸客戶、取得融資及查閱資料是不同的權利；改動其中一項，不會同時改動其餘各項。

講評 · 說明選擇方向的理據

如果保留選擇客戶和未來投資者的自由，值得放棄引薦機會，選擇 I 有理據。如果會面的價值足以彌補較少的現金緩衝及仍然適用的限制，選擇 C-narrow 也有理據。若要選擇會排除 N2 和 N3 的 C 原方案，就需要更有力的理據，說明它比 C-narrow 多出的現金為何值得。押後決定可保留選擇，但試點亦會延後。

講評 · 不要為想像中的銷售估價

C 排除三家準客戶，不等於失去三份合約；四場會面也不等於新增四家客戶。沒有概率或邊際貢獻的資料，便不能按期望值判定哪個方案較佳。應查核客戶探索會面的質素，了解客戶對這層投資關係的顧慮，並評估現金緩衝有多重要。不要假定獨立投資者可以免費提供同等的引薦機會。

講評 · 接受前先核實

應要求合資格顧問查閱完整文件，核實受限制的實體、產品範圍、期限、屆滿安排、融資同意權及資料保障措施。確認誰有責任安排會面，以及未有安排時有何後果。若審查後仍未能釐清重大條件，便不要接受。課堂上得出的結論不能確立安排是否合法，也不能令商業承諾自動履行。

教師說明

用四分鐘討論初始方案，四分鐘討論第二輪揭示的準客戶資料，再用六分鐘比較三項權利。問學生：限制較少是否等於沒有限制？一家企業獲准成為客戶，是否也獲准日後成為投資者？評核重點是有條件、有理據的策略選擇，不是股權攤薄計算、退出所得的分配次序，或聲稱企業投資者本質上有害。
