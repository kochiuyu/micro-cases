GVR-37 · 香港 · 15–20分鐘 · 類別股份權利 · 分層審批 · 經濟權利

大多數股東都贊成，還須取得誰的同意？

有表決支持，不等於已取得所有必要同意

股份權利不只涉及表決，也可涉及分派。管治指引有別於受影響類別股東的批准，另行看待公司的一般決定。本虛構練習訂有本身的嚴格同意規則，並非指每次發行新股都會改變類別股份權利，也不是在香港發行股份的範本。

課堂決定

你是 Harbour Fold 董事會的顧問。這家虛構的香港私人公司經營展覽裝置業務，正計劃擴展。公司有一百股附表決權的普通股，持有其中七十股的股東支持發行新股集資。這只是有記錄的商業支持，不代表已取得配發授權、已修訂公司章程，或已取得任何個別類別股東的同意。

現有四名優先股股東，各自持有相同數目的 P 股。P 股在一般股東會議上沒有表決權，但在向股東作出分派時享有受保障的優先權。P 股股東有權以該類別股東的身分另行決定是否同意。擬發行的 N 股在一般股東會議上也沒有表決權，因此兩個方案都不會改變現有普通股的票數。

按個案所訂的章程規則，若擬發行的股份在向股東作出分派時順位先於 P 股，必須先取得全體四名 P 股股東的書面同意。順位明確低於 P 股的股份不觸發這項特定規則。公司仍須取得其他所需批准、履行董事職責及通知規定，並核對生效日期和辦理存檔；這並不是一份完整的法律核對清單。

方案 J 把 N 股的順位改為明確低於 P 股。準投資者會提供1百萬港元，足以推行規模較小的首階段擴展。方案 C 則就 N 股擬享有的優先順位尋求 P 股股東所須給予的同意，以換取1.2百萬港元，足以推行原定的兩個階段。兩個項目在營運上均可行，但公司尚未接受任何一項融資。

無論採用哪個方案，都有合資格的顧問可提供協助，也有一段已有資金支持的籌備期。即使兩個方案都未能完成，現有業務仍可繼續運作。沒有任何期限迫使任何人放棄權利。你的任務是建議哪個方案值得進一步籌備，而不是執行發行。董事會尚未收到分派條款的詳細文本，也未收到 P 股股東的回應。

你的決定

你會暫時選擇籌備哪個方案？為甚麼即使有七十票普通股支持，而且表決權維持不變，仍不能判斷是否須取得 P 股股東同意？在建議發行任何股份之前，你會要求查看哪項具體分派條款，以及甚麼同意證明？

第二輪 · 多了一項資料

本練習所指的一年，是由發行日或其周年日起計的十二個月。優先順位只適用於向股東派發股息，與債權人的申索或表決權無關。

按 N 股的擬議條款，每年如依法宣派股息，N 股可先於 P 股收取該年度股東股息總額中的首20,000港元，其後才輪到 P 股行使原有的優先權。個案所訂的規則明訂，這種較高的支付順位會影響 P 股受保障的權利。股息、利潤或還款一概沒有保證，債權人的權利亦維持不變。

四名 P 股股東均表示願意接受範圍較窄的修訂：N 股只可在首年依法宣派的股息總額中，先於 P 股收取最多10,000港元。由第二年起，N 股的順位必須明確低於 P 股。首年未獲支付的款額一律失效，不會累積為欠款，不得延期，日後也不能再主張優先受償。

準投資者確認，願意按這些收窄後的條款提供同樣的1.2百萬港元。這只是不具約束力的磋商意向，並非已簽署的認購承諾。四名 P 股股東表示願意接受，也不等於該類別股東已正式書面同意。經修訂的文書、一般授權及股份發行，均尚未獲批准或完成。

兩個方案仍可考慮。J 不改變 P 股原有的優先順位，但集資額較少；經修訂的 C 可為規模較大的項目提供資金，但須就確切的修訂條款取得該類別股東同意。董事會沒有概率預測或估值證據，無法衡量讓出優先順位的代價，也無法判斷哪個項目能創造較高的淨價值。

你的決定

收窄條款後，方案 C 是否仍須另行取得 P 股股東同意？請建議接下來可在權限內採取的步驟，並說明哪些事項仍須暫緩。比較 J 與經修訂的 C 時，不要把接受意向當成已取得的同意，也不要把額外200,000港元的融資視為不付代價便可取得的價值。

講評 · 先看誰有權同意

一百票普通股表決權中有七十票支持，代表70%的商業支持，並不代表四名 P 股股東全數同意。P 股股東即使沒有一般表決權，仍可另行同意或拒絕改變其支付順位。全體一致同意是這家虛構公司章程的要求，並非聲稱普遍適用的法定門檻。

公司的一般授權與該類別股東同意，回答的是不同問題。兩者如適用，董事會都必須確認已取得，並須符合其餘法律及程序要求。即使大多數股東相信擴展對所有人都有利，也不能把普通股股東的支持記錄當作 P 股股東的同意。

講評 · 受保障的是經濟權利

按原有建議，N 股可優先收取首20,000港元，順位因而先於 P 股。根據列明的規則，即使任何人的一般表決權都沒有改變，仍須取得同意。收窄後的首年10,000港元優先權，仍使 N 股暫時排在 P 股之前，因此同一規則仍然適用。金額減少或期限縮短，並不改變這項變更的性質。

J 把 N 股的順位定在 P 股之後，因此不觸發這項特定的優先順位同意規則。這個結論取決於個案所訂的條款，並不意味着任何地方發行順位較低的股份都不受任何保障條文約束，也不意味着公司可以忽略其他受影響的權利、合約限制、批准或法定要求。

講評 · 籌備徵求同意，不要假定已獲同意

如果董事會重視為兩個階段提供資金，並接受這項有明確限度的讓步，籌備經修訂的 C 是有理據的選擇。應向全體四名 P 股股東傳閱同一份條款明確的修訂方案，讓他們在掌握資料後作出考慮，並按適當程序取得所須的書面同意。記錄同意的範圍及生效日期，並確保每名股東仍可拒絕。

獲批准的條款必須列明首年10,000港元的上限、任何未付款額一律失效，以及由第二年起順位明確低於 P 股。不要讓後續文件在未有說明的情況下恢復20,000港元的額度、永久優先權或累計欠款。任何仍影響權利而又經改動的方案，都必須重新循適當程序取得批准，不能沿用就不同條款取得的同意。

講評 · 方案可行不等於股份已發行

在獲授權的顧問核實最終文件、有效的公司決定、所須的該類別股東同意及適用的完成條件之前，任何股份配發、認購承諾或資金轉移都須暫緩。課堂上認同 C，並不等於有權執行。如果未能取得同意，或投資者更改條款，便應重新考慮 J 或延後發行；不可單憑大多數股東的支持發行股份。

如果保留 P 股的優先順位、推行規模較小但可行的首階段，更符合公司的利益，J 仍是有理據的選擇。經修訂的 C 多提供200,000港元融資，並不是已量度的200,000港元利潤。視乎依法宣派的股息，這項臨時優先權可帶來零至10,000港元的付款，但本個案並無預測這筆付款或項目的回報。
