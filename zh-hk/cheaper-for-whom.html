ECO-07 · 香港 · 10–15分鐘 · 經濟學 · 外部成本 · 噪音緩減

送貨更便宜，對誰而言？

新聞裏 · 交易以外：營業噪音的影響

2023年8月9日，香港環境保護署就擬議的噪音管制修訂徵詢意見，建議包括管制店舖及小販使用擴音器。

這項過往的諮詢反映社會關注營業噪音對他人的影響，並非現行法例的指引，也不是送貨規則。下文的店舖和卸貨選項均屬虛構。

課堂決定

虛構的課堂情境。 香港一間社區小店經住宅旁的共用通道收貨。下一批貨物若採用標準搬運方式 A，店舖須付100港元；若採用較安靜的方式 B，則須付180港元。店方想控制開支，同時兼顧鄰居。

兩種方式在同一時間搬運同一批貨物，貨車行程及服務質素亦相同，安全工作安排維持不變。兩者有差異的搬運成本已全部計入；相同的成本在比較時互相抵銷。就本練習而言，兩種方式在符合所有適用規定的前提下均可行。經濟計算不能凌駕限制、權利或安全要求。

為以同一單位比較滋擾程度，請採用下列虛構的貨幣等值估算。這些數值並非住戶帳單、賠償款項、罰款、在香港實測的損害金額，也不是由分貝換算而來。居民不會收到任何款項。估算亦無法涵蓋每個人的感受。

每次送貨A · 標準方式B · 較安靜的服務
店舖的搬運成本HK$100HK$180
鄰居承受的滋擾（估算）HK$150HK$20

鄰居承受的滋擾估算不計入店舖的帳單。在這個簡化比較中，銷售、排放、交通擠塞和員工安全均不變。

你的決定

單從店舖角度看，哪種方式最便宜？若也計及鄰居承受的滋擾，你會建議哪一種？請先提出初步建議，並指出甚麼證據最可能令你改變建議。

第二輪 · 改了一個事實

承運商提出在相同送貨時段採用方式 C：使用妥善保養、配有較安靜車輪的手推車，在會發出噪音的接觸點鋪設保護墊，並由受過訓練的員工按程序搬運。相對 A，這種方式多花40港元，已包括分攤的設備成本、設置成本及員工工時成本。因此，店舖每次送貨須付140港元。

在這個虛構情境中，針對現場的評估和居民意見支持把 C 的滋擾成本估算為30港元。評估針對搬運時實際發出噪音的位置，並無聲稱可令貨車不再發出聲響，或消除所有噪音。其他假設維持不變。

這是有用的正面證據，但並非實地試驗，也不是保證。與 B 相比，C 可減少店舖開支，但鄰居承受的滋擾估算略高。承運商並未提出任何賠償安排。

你的決定

你現在會選 C，還是保留 B？請比較模型中的合計成本，以及成本由誰承擔。採用 C 前，你會要求核實哪一項事項，或訂明哪一項操作條件？

帳單未必反映交易以外的成本

A 令店舖付出100港元，亦令鄰居承受估計相當於150港元的滋擾，合計250港元。B 令店舖付出180港元，鄰居承受的滋擾估計相當於20港元，合計200港元。

B 要店舖多花80港元，但令滋擾估算減少130港元。在模型中，B 的合計成本低50港元。若只看帳單，A 仍然最便宜。

負外部性是指交易以外的人承受了不利影響，而交易價格並未反映這項影響。在本個案中，鄰居承受的滋擾就是外部成本，並非搬運帳單上已計入的另一項收費。

一項可行的改善帶來新選擇

C 的搬運成本為100港元 + 40港元 = 140港元，再加上估計相當於30港元的滋擾，合計170港元。在這個模型中，這比 A 低80港元，比 B 低30港元。

噪音緩減措施提供了一個有用的新選項，店舖不必只在原來兩種方式之間選擇。額外設備及操作程序並非沒有成本；相關成本已明確計入40港元，不要重複計算。

按這些估算，C 在模型中的合計成本最低。這並非經量度得出的社會最優結果，也不表示每項影響都已準確折算為金額。

總成本較低，不等於人人受惠

與 B 相比，C 令店舖節省40港元，卻令鄰居承受的滋擾估算增加10港元。合計成本減少30港元，但鄰居不會自動分享店舖節省的款項。按題目所列的選項，沒有人獲得賠償。

只要操作安排可靠，並顧及受影響人士，便可基於較低的合計成本支持 C。B 較能保障鄰居，因此仍有理據支持。除了總成本，也要解釋成本如何分擔。

把損害折算為金額，不等於獲准造成損害，也不能取代居民的權利。如果某種方式不獲准採用，或無法安全操作，經濟比較並不會令它成為可行選項。

確保所選方式在實際操作中可行

若選 C，須確認設備獲妥善保養、保護墊鋪在評估所指的接觸點、員工依照搬運程序操作，而且通道仍可安全使用。指定由誰接收居民意見，以及由誰處理反覆出現的滋擾。可信的評估有助作決定，但仍須查核實際操作。

若選 B，須確認報價所指的較安靜服務，確實採用比較中滋擾較少的方式。檢視任何一個選項時，貨量和送貨時間都應維持可比。單憑沒有投訴，並不能確定毫無滋擾。

把這些估算視為值得重新檢視的假設。它們說明為甚麼帳單以外的成本也重要，但不表示每項決定都要化為一個總數，或無限期押後。

教師說明

要求學生兼顧店舖和鄰居的角度，提出初步建議。公布新資料後，問學生由 B 改用 C 時，誰得益、誰受損。不要給「C 對所有人都最好」這個答案分數：鄰居承受的滋擾估算由20港元升至30港元。

選做：敏感度分析。若店舖採用 C 的成本維持在140港元，而滋擾估算為60港元，C 的合計成本便與 B 的200港元相同。滋擾估算高於60港元時，B 的合計成本較低。這是取決於上述條件的臨界值，不是獲准的噪音上限。

所有數值均為虛構；滋擾數值是貨幣等值，並非透過調查得出的受影響者願意接受的賠償金額，也不是實測的損害。不要據此推斷有賠償、已獲法律許可、排放有所減少，或存在適用於所有送貨情況的通則。本個案的重點是區分私人成本與外部成本，並看科技如何改變兩者之間的取捨。
