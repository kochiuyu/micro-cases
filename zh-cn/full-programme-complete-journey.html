HSP-37 · 香港 · 15–20分钟 · 会议议程安排 · 参会流程 · 须预留的场次衔接时间

议程排满了，参会流程走得完吗？

议程也是参会者要走的一段流程

万维网联盟（W3C）和会议无障碍指南都鼓励主办方围绕参会者的需求做安排，而不只考虑演讲内容。马萨诸塞州的公共卫生指南明确指出，安排休息时要考虑参会者在不同活动之间的移动。这些都是规划参考，不是通用时间表，也不是对香港法律的说明。下文的会议和时间安排均属虚构。

课堂决策

你负责为虚构的 Harbour Exchange 安排议程。这是一场在香港举行、为期半天的专业会议。二十四名成年代表选择了完整的学习流程：全体会议、工作坊 A、工作坊 B 和闭幕讨论。每位代表都希望从头到尾参加这四场活动。仅仅进过每个会场，并不能实现这个目标。

所有参会者和演讲者都能留到13:00。两套方案的会场、人员、无障碍材料、协助服务和应急安排相同，相关经费均已落实。场地和支持服务可用至13:00，无需额外付费。两套方案都未对外公布，也未写入合同，因此不存在收回参会者已有权益的问题。

全体会议在 A 厅举行，时间为09:00–09:45。工作坊 A 也在这里举行，10:00开始，原预计10:40结束。工作坊 B 在 B 厅举行，闭幕讨论则回到 A 厅。两套方案的区别只在于后面这两场活动的时间。

场次之间，必须为这组参会者留出十五分钟，用于休息和处理个人需要。如需换厅，还要另外留出十分钟，包括就座时间。这两段时间不重叠，是针对本案例整个团体商定的要求，不是医学诊断，也不是通用的无障碍最低标准。两段时间都不能缩短。

全体会议后的十五分钟足够，因为大家继续留在 A 厅。工作坊 A 和 B 都不能改换场地，也没有远程替代或并行场次。B 开头的十分钟有一项必不可少的练习，不会重做。主办方要选的是一套能完整落实的参会流程，而不是让名义上的到场人数尽可能多。

按约定，全体会议、工作坊 A 和工作坊 B 结束后都要留出休息时间。闭幕讨论后，这组参会者不再需要安排休息；有经费保障的无障碍离场安排耗时五分钟。这是针对本虚构团体另行确认的要求，不适用于其他活动。

第二轮 · 多了一项资料

一次完整彩排确认，工作坊 A 的关键演示需要五十分钟，而不是四十分钟。在本课堂情境中，这一时长是固定的：A 必须安排在10:00–10:50。删减内容就无法兑现对工作坊内容的承诺。其他时长、开始时间和无障碍要求均不变。

试行 C 方案时，出席记录显示二十四名代表都参加了两场工作坊，因为只要进过场就算出席，不记录何时到场，也不记录是否完整参加。A 结束后，大家按约定休息十五分钟，再用十分钟换厅。B 仍按议程上列出的时间开始和结束。这些是为分析问题而虚构的观察结果，并非因果研究。

会议推出前，团队仍可在两套完整方案中任选其一，但不能单独调整某个场次，不能延长到13:00以后，也不能要求代表压缩休息或换厅时间，或错过 A 的部分内容。所有参会者和费用已有预算保障的供应商都能接受 L 较晚结束，但选 L 就不能像选 C 那样早离场。

你的决策

现在，哪套方案能让参会者完整参加所有必需场次？算出按 C 方案到达工作坊 B 的时间，以及会错过多少分钟。解释为什么出席记录看起来没问题，参会体验却不完整，并说明在会议推出前可以怎样做更有效的核查。

讲评 · 彩排前

按原计划，工作坊 A 在10:40结束。休息到10:55，换厅到11:05。C 的工作坊 B 正好在这时开始，没有任何余量。L 的 B 在11:20开始，扣除必要的休息和换厅时间后，还剩十五分钟。按最初给出的时长，两套参会流程都可行。

B 结束后，两套方案在闭幕讨论前都留出二十五分钟：十五分钟休息，十分钟换厅。C 的 B 在11:45结束，参会者于12:10到达闭幕讨论会场；L 的 B 在12:00结束，参会者于12:25到达。这两段衔接都没有额外余量。

讲评 · 重新推算实际参会流程

彩排后，工作坊 A 在10:50结束。必须预留的休息时间是10:50–11:05，换厅时间是11:05–11:15。按 C 方案，参会者到达时，工作坊 B 已经从11:05开始了十分钟。虽然大家之后都能进场并被记为出席，但已经错过了开头的关键练习。

L 的工作坊 B 在11:20开始，比参会者到场晚五分钟。大家可以完整参加 B，直到12:00；随后休息到12:15，换厅到12:25，再参加闭幕讨论，直到12:55。此时距离13:00的截止时间还剩五分钟。这里没有凭空增加场次或人手，也没有假定大家能走得更快。

按题设对完整参会流程的要求，应选 L。L 比 C 晚十五分钟结束。即使参会者已经接受这一点，不能早点离场仍是实实在在的代价。C 若维持原样，就无法满足新要求。这是在给定条件下得出的确定性可行性结论，并不能证明议程越长，就一定越有利于学习或身心状态。

讲评 · 出席不等于完整参加

按 C 方案，出席记录显示每场工作坊都有二十四人参加，但没有人参加到 B 开头的十分钟。合计错过 24 × 10 = 240 人·分钟。这只是时长合计，不是实测的学习损失，也不是身心状态评分，更不能说明 B 的其余内容都没有价值。

不要为了让指标看起来好看，就把“完整参加”改成“进过场”。要分别核查参会者是否在关键练习前到场、是否完整参与了必需内容，以及他们自己是否表示能按安排休息和换厅。清点人数只能回答谁来过，不能说明设计好的参会流程是否走得完。

讲评 · 明确方案的适用边界

L 在 B 开始前留出的五分钟，并不能应对所有超时。B 到闭幕讨论的衔接，扣除必须预留的休息和换厅时间后，仍没有额外余量。在声称方案能可靠落实之前，要用实际提供的支持服务走一遍完整流程，确认各场次的时长切合实际，并明确约定出现意外时如何应对。

两套方案都不能成为撤掉无障碍支持或催促参会者加快脚步的理由。实际需求可能变化，参会者也始终可以自行离开。这里的计算只检验为题设团体提供的完整参会流程是否可行，并不是说应该要求每位参会者都走完。

教师说明

在工作坊 A 结束后画出三个独立的时间段：必须预留的休息时间、换厅时间和剩余余量。然后把 A 原先的四十分钟改为五十分钟。请学生解释：为什么出席人数完全一样，却可能掩盖错过的十分钟？为什么闭幕讨论后即使还有空余时间，也补不回错过的开场练习？

HSP-09 围绕来宾的参会目的选择接待活动的引导方式；HSP-27 在固定的参观时段内安排遗产证据的呈现顺序。本案例检验的是场次超时后，完整参会流程还能否走完，以及仅凭进场人数为何可能误判。所有要求和结果均属虚构。所列来源有助于区分不同的规划问题，并不提供本案例的数字假设、医学结论或法律建议。

来源与案例假设 · 选读

原计划：A 在10:40结束 + 15分钟休息 + 10分钟换厅 = 11:05到场；C 的 B 在11:05开始，无余量；L 在11:20开始，余量为15分钟。调整后：A 在10:50结束 + 15分钟休息 + 10分钟换厅 = 11:15到场；C 会错过 B 的10分钟，L 还有5分钟余量。C 的 B 在11:45结束 + 25分钟 = 12:10开始闭幕讨论，12:40结束。L 的 B 在12:00结束 + 25分钟 = 12:25开始闭幕讨论，12:55结束，距支持服务在13:00截止还有五分钟。两套方案中，B 均为40分钟，闭幕讨论均为30分钟。L 晚15分钟结束，所有人都接受，且没有额外费用。24名代表 × 每人错过10分钟 = 240人·分钟，并非量化的学习损失。休息和换厅是两项独立、固定的要求，不能催促参会者、用其他安排替代，也不能假定可免费增加资源。进场人数不等于完整参加的人数。这是确定性的可行性判断，不是预测、通用的无障碍最低标准，也不是法律或医学结论。全体会议、A 和 B 之后都安排休息；按题设，这组参会者在闭幕讨论后无需再安排休息。有经费保障的无障碍离场耗时五分钟，因此按 L 方案，参会者在13:00全部离场。
