ECO-07 · 香港 · 10–15分钟 · 经济学 · 外部成本 · 降噪措施

送货更便宜，对谁而言？

新闻里 · 交易之外的经营噪声

2023年8月9日，香港环境保护署就噪声管制修订建议征询意见，其中包括对店铺和小贩使用扬声器的管制建议。

这次历史咨询反映了人们对经营噪声影响他人的关注。它不是关于现行法律的意见，也不是送货规定。下文的店铺和卸货方案均为虚构。

课堂决策

虚构的课堂情境。 香港一家社区小店通过住宅旁的一处共用通道收货。下一次送货，采用常规搬运方式 A，店铺要付100港元；采用更安静的搬运方式 B，则要付180港元。店主想控制开支，也不想忽视邻居的感受。

两种方式运送同样的货物，送货时间、货车行程和服务质量都相同，安全作业安排也不变。两种方式之间有差异的搬运成本已全部计入，相同的成本在比较时相互抵消。本练习假定，只要符合所有适用要求，两种方式都可行。经济账不能凌驾于限制规定、相关权利或安全要求之上。

为了用同一单位比较扰民程度，请采用下表中虚构的货币等值估算。这些数字不是住户账单、赔偿款或罚款，也不是在香港实测的损害金额，更不是由分贝换算而来。没有任何款项支付给居民。这些估算也无法反映每个人的实际感受。

每次送货A · 常规搬运B · 更安静的搬运服务
店铺的搬运成本HK$100HK$180
邻居承受的扰民成本估算HK$150HK$20

邻居承受的扰民成本单独估算，不计入店铺账单。在这项简化比较中，销售、排放、拥堵和作业人员的安全状况均不变。

你的决策

只算店铺自己的开支，哪种方式最便宜？如果把对邻居的干扰也算进去，你会推荐哪种方式？先给出初步建议，再说说什么证据最可能让你改变建议。

第二轮 · 改了一个事实

承运商提出方式 C，送货时间不变：使用保养到位、车轮噪声更小的手推车，在产生噪声的接触点铺设防护垫，并由受过培训的员工按规程搬运。相较于 A，C 多花40港元，已包含设备费用分摊、布置和人员工时。因此，店铺每次送货要付140港元。

在这个虚构情境中，针对现场的评估和居民反馈支持将 C 的扰民成本估为30港元。评估针对搬运中实际产生噪声的环节，并不声称能让货车不发出声音，或消除所有噪声。其他假设不变。

这是有用的正面证据，但并不来自真实试验，也不是保证。与 B 相比，C 让店铺少花钱，但邻居承受的扰民成本估算略高。没有人提出赔偿安排。

你的决策

现在你会改选 C，还是继续用 B？比较模型算出的合计成本，并说明各部分由谁承担。在采用 C 之前，你会要求核查哪一项，或要求满足哪一项作业条件？

有些成本留在交易之外，并不出现在账单上

采用 A，店铺要付100港元，邻居还要承受估算为150港元的扰民成本，合计250港元。采用 B，店铺要付180港元，邻居承受的扰民成本估算为20港元，合计200港元。

采用 B，店铺要多花80港元，但扰民成本估算减少130港元。按模型计算，合计成本低50港元。只看账单，A 仍然最便宜。

负外部性是指由交易之外的人承受、却未反映在交易价格中的不利影响。这里，邻居承受的扰民成本就是外部成本，并不是搬运账单里已经包含的另一笔收费。

一项可操作的改进，带来了新选项

C 的搬运成本为100港元 + 40港元 = 140港元，再加上估算为30港元的扰民成本，合计170港元。在这个模型中，C 比 A 低80港元，比 B 低30港元。

降噪措施提供了一个有用的新选项，而不只是让店铺在原来的两种方式中二选一。额外的设备和作业规程并不是免费的，相关成本已经明确计入40港元，不要重复计算。

按这些估算，C 在模型中的合计成本最低。这不是通过实测得出的社会最优结果，也不意味着每一种影响都得到了准确计价。

总成本更低，不等于人人受益

与 B 相比，C 让店铺节省40港元，却使邻居承受的扰民成本估算增加10港元。合计成本减少30港元，但邻居不会自动分享到店铺省下的钱。在题设给出的选项中，没有人获得赔偿。

只要作业方式能可靠落实，并顾及受影响的人，就可以用较低的合计成本为选择 C 辩护。B 也仍有理由选，因为它能更好地保护邻居。除了合计成本，还要说清楚成本由谁承担。

用货币估算损害，不等于获准给他人造成损害，也不能替代居民的权利。如果某种方式不被允许，或无法安全作业，经济上的比较也不能让它成为可选方案。

让选定的方式在实际作业中落实

如果选 C，要确认设备保养到位，防护垫铺在评估指出的接触点，员工按规程搬运，共用通道仍可安全通行。明确由谁接收居民反馈、由谁处理反复出现的扰民问题。可信的评估能支持决策，但不能代替对实际作业的核查。

如果选 B，要确认报价中的更安静服务确实采用了比较时所依据的低扰民方式。评估任何一种方式时，都要保持送货量和送货时间可比。仅凭没有投诉，不能认定完全没有扰民。

把这些估算当作值得重新检验的假设。它们说明账单之外的成本为什么重要，并不意味着每项决策都要归结为一个总数，或无限期拖延。

教师说明

要求学生从店铺和邻居两个角度提出初步建议。公布新信息后，追问从 B 改用 C，谁受益、谁受损。不要给“C 对所有人都最好”这样的回答加分：邻居承受的扰民成本估算从20港元升至30港元。

可选的敏感性分析：如果 C 给店铺带来的成本固定为140港元，那么扰民成本估为60港元时，C 的合计成本恰好等于 B 的200港元。超过60港元，B 的合计成本更低。这是给定条件下的临界值，不是允许的噪声限值。

所有数值均为虚构。扰民数值是货币等值估算，并非调查得出的受偿意愿，也不是实测损害。不要据此推断有人获得赔偿、已经取得法律许可、排放有所减少，或可以得出普遍适用的送货规则。本案例的教学重点是区分私人成本和外部成本，并理解技术如何改变两者之间的权衡。
