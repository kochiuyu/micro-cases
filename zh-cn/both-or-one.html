两节课打包卖，人人都得买两节吗？

新闻里 · 可以自己选的套餐

2025年7月3日，香港旺角帝盛酒店推广了一款客房套餐，住客可任选三项礼遇，备选项目包括交通或餐饮。

这则过去的企业公告为讨论如何组合服务、如何保留选择提供了一个切入点。酒店套餐与本案例中虚构工作室的购买方案不同；这则公告既不能证明收入有所增加，也不说明酒店目前仍提供该套餐。

课堂决策

虚构的课堂情境。 香港一家手工工作室在不同时段开设毛笔字和折纸课。两节课各有用处，顾客可以只上一节，也可以两节都上。无论采用哪种销售方案，课程质量不变，名额充足，现有人员和场地成本也相同。

每位顾客每上一节课，材料成本为20港元；两节都上则为40港元。打包不会节省成本。本练习不考虑额外的预订或销售方案管理成本、税费、退款或时间冲突；课程也不能转让、转售或重复购买。

起初只有两位顾客，A 和 B 各一位。下表是为练习设定的最高支付意愿，并非调查结果。各项估值已考虑时间和精力，顾客的预算也都充足。每位顾客在可选的购买方式中，挑选下列差额非负且最大的那一种： 估值减去总价。什么都不买，所得为零。

分开卖： 每节90港元，两节共180港元。 只卖套餐： 两节合售125港元，均不单卖。两节一起上，估值也只是单节估值之和，没有额外价值。

比较的是边际贡献，即销售收入减去增量材料成本，不是工作室的完整利润。顾客会参加自己选的课程。按这些价格，不会出现收益并列的选项。

你的决策

面对这两位顾客，你会暂时采用哪种销售方案？判断他们各自会怎么买，再比较买家收益和工作室的边际贡献。什么样的顾客可能让你改变选择？

第二轮 · 改了一个事实

销售方案公布前，负责预订的同事又加入了 顾客 C：这位顾客对毛笔字课的估值为100港元，对折纸课的估值为零。现在练习中 A、B、C 各有一位，并不是在预测各类顾客所占的比例。

预订系统可以在不增加管理成本的情况下提供第三种销售方案：两节课仍可按每节90港元单买，同时也可按125港元买两节课的套餐。这种做法叫 混合捆绑。除此之外，价格、质量、材料成本、名额和上课时段都不变，没有隐藏费用，也不会自动加购。

用同样的三位买家比较三种备选销售方案。每位买家仍会选择估值减去价格后差额最大的选项，而不是随便挑一个有正收益的选项。

你的决策

面对这三位顾客，你会只卖单节课、只卖套餐，还是采用混合捆绑方案？算出他们实际会怎么选，再说出一项你会在正式推出前检验的现实成本或需求假设。

只看起初两位买家，套餐有优势

分开卖时，A 选毛笔字，B 选折纸。每位买家的收益都是100港元 − 90港元 = 10港元。收入为180港元，材料成本为40港元，边际贡献为140港元。

只卖套餐时，两位顾客都买两节课。每位买家的收益都是140港元 − 125港元 = 15港元。收入为250港元，但共占用四个单节课名额，材料成本为80港元，边际贡献为170港元。

在这个只有两位买家的模型里，边际贡献增加30港元，买家总收益增加10港元。成本也上升了；套餐没有创造额外价值，也没有让材料变便宜。

用同样的三位顾客重新比较各方案

只卖单节课： A 和 C 选毛笔字，B 选折纸。收入270港元 − 材料成本60港元 = 边际贡献210港元。每位买家的收益为10港元，合计30港元。

只卖套餐： A 和 B 选套餐；C 什么都不买，因为100港元 − 125港元的结果为负。收入250港元 − 材料成本80港元 = 边际贡献170港元。买家总收益为30港元。

混合捆绑方案： A 和 B 选套餐，C 选毛笔字。收入340港元 − 材料成本100港元 = 边际贡献240港元。买家收益分别为15港元、15港元和10港元，合计40港元。

在给定假设下，混合捆绑的边际贡献在这三种备选方案中最高。不要拿最初两位买家的合计数与后来三位买家的合计数相比，再把差额归因于销售方案。

要判断买家会怎么选，不能只看他们买不买得起

在混合捆绑方案下，A 和 B 买套餐可获得15港元的收益，高于购买各自最喜欢的单节课所得的10港元。对 C 来说，单买毛笔字课可获得10港元的收益，比买套餐所得的−25港元或什么都不买更划算。

保留单买选项，既能让 C 参加，也不妨碍 A 和 B 选自己更喜欢的套餐。买家即使买得起两节课，也不一定会选内容最多的套餐；还要看有哪些备选项。

不要把模型里的结果推得太远

这里比较的是三种备选方案，并未证明这些价格是最优的。顾客估值或材料成本不同、课程名额有限，或者需要额外管理，都可能改变结果。为了教学，这里直接给出了确切的支付意愿；工作室通常看不到这些信息。

要确保单节课确实可以买到，并说清总价、包含哪些课程、上课时间和适用条件。本例不能证明所有套餐都对所有消费者有利，也不能回答竞争法问题。

教师说明

第一次投票时，只让学生看到 A 和 B，再加入 C 和可行的混合捆绑方案。先让学生逐一找出每位买家收益最高的购买选项，再汇总收入。课程估值可以直接相加；没有假定两节一起上会因互补而产生额外价值。

公布新信息后，每次比较都用同样的三位买家。在给定价格下，混合捆绑的边际贡献比分开卖高30港元，比只卖套餐高70港元；这些数字不是对香港市场的估计。边际贡献没有扣除不变的人员和场地成本，因此这里没有给出完整的利润水平。

可加一道检验题：如果混合捆绑方案的套餐价改为135港元，单节课仍为90港元，会怎样？A 和 B 会各自选最喜欢的单节课，因为10港元的收益高于套餐的5港元。这是另一个情境，不是对主案例价格的修订。竞争对手的行为、行业福利和法律评估均不在本模型范围内。
