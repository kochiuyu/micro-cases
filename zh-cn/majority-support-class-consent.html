GVR-37 · 香港 · 15–20分钟 · 类别股份权利 · 分层审批 · 经济权利

多数股东都同意了，还需要谁同意？

有表决支持，不等于取得了所有必要的同意

股份权利既可以涉及表决，也可以涉及向股东分配款项。公司治理指引区分公司层面的一般决策和受影响类别股东的批准。本虚构案例设定了自己的严格同意规则，并不是说每次发行新股都会改变类别股份权利，也不是在香港发行股份的操作范本。

课堂决策

你是虚构公司 Harbour Fold 董事会的顾问。这家香港的非上市展陈装置公司正计划扩张。公司共有一百股有表决权的普通股，其中七十股的持有人支持通过发行新股融资。这只是已有记录的商业支持，并不意味着已经取得股份配发授权、完成章程修订，或取得任何类别股东的单独同意。

现有四名优先股股东，各自持有相同数量的 P 股。P 股在股东大会上没有一般表决权，但在向股东分配款项时享有受保护的优先顺位。P 股股东有权作为独立类别决定是否同意。拟发行的 N 股也没有一般表决权。因此，无论采用哪个方案，现有普通股的表决票数都不会改变。

按案例给出的章程规则，凡拟发行在股东分配中顺位高于 P 股的股份，都须事先取得全体四名 P 股股东的书面同意。顺位明确排在 P 股之后的股份不触发这项特定规则。公司仍须取得其他必要批准、履行董事义务、发出通知、核对生效日期并办理申报；这并不是一份完整的法律事项清单。

方案 J 调整 N 股条款，使其顺位明确排在 P 股之后。潜在投资者将出资100万港元，足以支持规模较小的第一阶段扩张。方案 C 则就拟给予 N 股的优先顺位征求所需的 P 股股东同意，换取120万港元，足以支持计划中的两个阶段。两个项目在运营上都可行，但两项融资安排均尚未获接受。

不论选哪条路径，都有合资格的顾问可提供协助，也留出了经费有保障的准备时间。即便两项融资都未能完成，现有业务也会继续运营。没有任何截止期限迫使任何人放弃权利。你要推荐的是下一步准备哪个方案，而不是执行发行。分配条款的具体措辞和 P 股股东的回应尚未送达董事会。

两条附条件的融资路径
方案新 N 股的顺位完成后可获融资
J明确排在 P 股之后100万港元
C优先顺位，须经 P 股股东同意120万港元
你的决策

你会先着手准备哪个方案？请解释为什么七十票普通股支持、现有表决权也不变，仍不足以判断是否需要 P 股股东同意。在建议发行任何股份前，你会要求查看哪项具体的分配条款，以及什么样的同意证明？

第二轮 · 多了一项资料

本案例所说的一年，是指从发行日或其周年日起算的十二个月。这里的优先顺位只涉及向股东派发股息，不涉及债权人的债权或股东的表决权。

按 N 股的拟议条款，每年如依法宣派股息，股息总额中的首20,000港元由 N 股先于 P 股取得，随后才轮到享有现有优先顺位的 P 股。案例给出的规则明确规定，这种优先受偿顺位会影响 P 股受保护的权利。股息、利润或还款均无保证，债权人的权利也不变。

四名 P 股股东都表示，愿意接受一项范围更窄的修订：仅在第一年，N 股可以从依法宣派的股息中先于 P 股取得最多10,000港元。从第二年起，N 股的顺位必须明确排在 P 股之后。第一年未支付的额度失效，不形成欠款、不得延期，也不得在以后主张优先支付。

潜在投资者确认，在收窄优先权后仍愿意出资120万港元。这只是谈判中的意向，没有约束力，也不是已签署的认购协议。四名 P 股股东表示愿意接受，也不等于该类别股东已正式书面同意。修订后的文件、公司层面的一般授权及股份发行，均未获批准，也未完成。

两个方案仍可选择。J 不改变 P 股现有的优先顺位，但融资较少；修订后的 C 可以为较大的项目提供资金，但必须就修订后的确切条款取得规定的该类别股东同意。董事会没有可用的概率预测或估值证据，无法为让出的优先权定价，也无法判断哪个项目能创造更高的净价值。

你的决策

收窄后的 C 方案是否仍须单独取得 P 股股东同意？请建议下一步可以获准开展哪些工作，并说明哪些事项仍须暂缓。比较 J 和修订后的 C 时，不要把同意意向当成已经取得的正式同意，也不要把多筹到的200,000港元当成无成本获得的价值。

讲评 · 先看该数谁的票

一百票普通股表决票中有七十票支持，意味着商业支持度为70%，并不等于四名 P 股股东全部同意。即使没有一般表决权，P 股股东仍有权单独同意或拒绝改变其受偿顺位。全体一致同意是本虚构公司章程的要求，并不是说法律普遍设有这一门槛。

公司层面的一般授权和该类别股东同意回答的是不同的问题。凡适用，董事会都必须确认两者已经具备，并满足其余法律和程序要求。即使多数股东认为扩张对所有人都有利，也不能把普通股股东的支持记录当成 P 股股东同意。

讲评 · 变动涉及受保护的经济权利

拟议条款让 N 股优先取得首20,000港元，顺位排到了 P 股之前。按案例列明的规则，即使没有人的一般表决权发生变化，这也触发了同意要求。将优先权收窄至第一年的10,000港元，仍使 N 股暂时排在 P 股之前，因此仍触发同一规则。减少金额或缩短期限，并不改变这种变动的性质。

J 将 N 股的顺位明确排在 P 股之后，因此不触发这项特定的优先顺位同意规则。这个结论取决于案例给出的条款，并不意味着任何地方发行顺位靠后的股份都不受任何保护规则约束，也不意味着公司可以忽略其他受影响的权利、合同限制、审批或法定要求。

讲评 · 着手征求同意，不要预设同意

如果董事会重视为两个阶段都筹足资金，也接受这项有限的让步，那么着手准备修订后的 C 方案是有理由的。向全体四名 P 股股东发出同一份条款明确的修订方案，让他们在充分知情的基础上考虑，并按适当程序取得所需的书面同意。记录同意的范围和生效日期，保留每名股东拒绝的权利。

获批条款必须明确：第一年的上限为10,000港元，未支付的额度失效，从第二年起顺位明确排在 P 股之后。不要让后续文件悄悄把额度调回20,000港元、把优先权改为永久有效，或让未付款项累积成欠款。只要涉及受影响权利的方案再有变动，就必须重新履行相应审批程序，不能借用对其他条款的同意。

讲评 · 方案可行不等于发行已经完成

在获授权的顾问核实最终文件、公司决议的有效性、所需的该类别股东同意及适用的交割条件之前，任何股份配发、认购承诺或资金划转都应暂缓。课堂上支持 C 方案，并不构成执行授权。如果未能取得同意，或者投资者改变条件，就重新考虑 J 或推迟发行；不要仅凭多数股东支持就发行。

如果保留 P 股的优先顺位、推进规模较小但可行的阶段更符合公司利益，选择 J 仍有道理。修订后的 C 方案能多筹200,000港元，但这不是已测算出的200,000港元利润。视依法宣派的股息而定，这项临时优先权带来的支付额可能在零至10,000港元之间，但案例并未预测这笔款项或项目回报。

来源与案例假设 · 选读

课堂决策所需的资料，上文已经齐备。来源只供选读，用来交代出处和背景。

虚构公司原章程规定，凡在股东分配中给予高于 P 股的优先顺位，都须取得持股数相同的全体四名 P 股股东的书面同意。这不是默认的法定门槛。普通股支持票为70/100=70%，不等于该类别股东单独同意。N 股没有一般表决权，但经济上的优先顺位仍然重要。初始方案下，N 股可优先取得每年依法宣派股息中的首20000港元，无期限；修订后仅第一年可优先取得首10000港元，未支付的额度失效，第2年起顺位靠后。按案例规则，这两种条款都须经 P 股股东同意；J 的顺位明确排在 P 股之后，不触发这项特定规则，但其他保护仍然适用。J 融资1百万港元，C 融资1.2百万港元，相差200000港元，不是利润；没有预期收益或估值。所有意向均无约束力，尚未达成正式协议，也未完成交易。仅涉及依法作出的分配，不改变债权人的受偿顺位，也不保证回报。没有实际交易，也未执行任何法律手续。
