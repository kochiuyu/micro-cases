OPS-14 · 香港 · 10–15分钟 · 路线安排 · 时间窗 · 配送可行性

路线更短，却错过时间窗？

香港通行与装卸提示

运输署的一则公告将旺角指定路段自2026年7月13日起划为限制区。除获准人员外，其他人在这些路段装卸货物也受到限制。这说明，规划路线时，除了看路程长短，还得看通行和作业条件。

下面三个配送点均为虚构，不涉及真实客户地址。各点的装卸时间窗是虚构的现场条件，不是该公告规定的道路限制。

课堂决策

虚构的课堂情境。香港一名配送调度员有一辆厢式货车，装着三位客户的全部包裹。车辆完成装载检查和安全检查后，于上午9:00从配送站 D 出发，最迟须在11:00返回。两种方案使用同一名司机、同一辆车，载运能力和安全作业安排也相同，所需经费均已落实。每个配送点都需要连续十分钟完成安全卸货和签收。

现有两条候选路线：路线1先到 A，再到 B，接着到 C，最后返回 D；路线2先到 B，再到 A，接着到 C，最后返回 D。路线1更短，但路线2更早到达 B。只比较这两条路线，不主张其中任何一条是所有可能路线中最优的。

先按预约时间窗计算：A 为9:10–9:50，B 为9:20–10:00，C 为9:50–10:30。每个配送点的十分钟作业必须全部落在时间窗内，不是只要在窗内到达就行。提前到达时，有安全的地方可以等候。下表的行驶时间是固定的课堂假设，不代表对香港实际路况的承诺。发车前必须向各配送点确认现场条件。

第二轮 · 多了一项资料

发车前，A 确认收货团队和装卸月台现在都可以配合，整套作业最晚可在10:10完成。B 的楼宇管理方确认，装卸月台的规定更严格：不得早于9:20开始卸货，且最晚须在9:35全部卸完。单看 B 客户的预约，并不能知道这项楼宇规定。C 的9:50–10:30时间窗不变。

以上是在这个虚构配送日已经核实的条件。按所述方式使用公共道路和私人装卸月台均合法；不允许改在路边卸货，也不能无人签收就放下包裹，没有第二辆车可用，也不能提前发车。十分钟作业时间和行驶时间假设不变。不要缩减安全检查、超速行驶，也不要把截止时刻到达当成符合要求。

按确认后的时间窗重新计算两条候选路线。路线2全程多走三公里、多用十分钟，但它可能满足路线1无法满足的约束。案例没有给出任何可以让调度员通过支付罚金而获准错过时间窗的迟送处罚条款。

不只看地图上的路线，还要逐段核对时间

路线1：D 9:00 → A 9:15–9:25 → B 9:35–9:45 → C 10:00–10:10 → D 10:30。全程14公里，行驶60分钟，客户现场作业30分钟。这条路线符合原来的预约时间窗。

路线2：D 9:00 → B 9:20–9:30 → A 9:40–9:50 → C 10:10–10:20 → D 10:40。全程17公里，行驶70分钟，现场作业30分钟。这条路线也符合原来的时间窗，但在 A 恰好卡着原来的截止时刻完成。

核对调整后的约束

按确认后的条件，路线1在9:35到达 B，但还需要十分钟作业。到9:45才完成，超过了9:35的截止时刻。路线2在9:30完成 B 的作业，在9:50完成 A 的作业，在10:20完成 C 的作业。每站的整套作业都落在各自的时间窗内，车辆也在11:00前返回。

不能因为另一条路线更短，就认定多走的路是浪费。比较候选路线时，要先看是否可行，再考虑把距离缩到最短。早到了可以等，但在 B 做完得太晚，靠等待解决不了。

方案可行，不代表实际路况下也一定能准时

路线2在 B 的完工截止时刻前留有五分钟，在 C 留有十分钟。A 放宽时间窗后，在 A 作业更从容，但这不能消除后续配送点的时间限制。这些余量只对应各自的配送点，不是每一段都能反复动用的额外时间。

跟踪配送进度，按约定的方式联系调度员；如果延误使方案不再可行，就寻求合法合规的调整安排。未经同意，不要在允许的时间窗之外卸货，也不要违规停车或压缩安全作业时间。案例没有给出延误概率，也没有提供比较结果来证明这条路线在现实中既稳健又最优。

教师说明

让学生把行驶和现场作业分别标成独立的时段。第二轮新信息改变的是现场约束，不是行驶速度、货量或作业内容。要检查两条路线在初始条件下和调整后的可行性；不要给只看公里数的建议加分。

OPS-02 要选出哪些货物需要加急；OPS-07 比较的是服务柜台的等候情况。本案例关注的是：在各点都有作业时间窗的条件下，如何安排分处不同地点的配送顺序。有些路线安排接口把时间窗定义为可以开始作业的时段；本案例明确要求在窗内完成作业。不要用接口的惯例替代明确给出的客户条件。英国的安全指南仅供说明，不构成香港法律意见。

来源与案例假设 · 选读

课堂决策所需的资料，上文已经齐备。来源只供选读，用来交代出处和背景。

所有配送点、包裹、行驶时间、距离和时间窗均为原创虚构设定。只有一辆车，所有货物经检查后恰好在9:00准备就绪，最迟11:00返回；两条候选路线在载运能力、装载顺序和安全作业安排上没有差异，所需经费均已落实。十分钟涵盖安全卸货和签收的全部作业，不可压缩。整套作业必须落在时间窗内，起止边界时刻均计入。最初路线1和路线2都符合时间窗。确认后，A 的截止时刻从9:50延至10:10；B 经楼宇管理方核实，截止时刻从10:00提前到9:35。路线1在 B 不再可行；路线2可行，在 B 有五分钟余量，在 C 有十分钟。行驶时间是外部给定的，不意味着各路段每公里用时相同。总距离分别为14/17公里，行驶时间合计分别为60/70分钟，总用时分别为90/100分钟。发车后或到达规定的返程终点前，没有未计入的配送站作业。只比较两条给定路线，并未穷举寻优。未使用真实地址，也未调用路线服务接口。现场装卸条件与公共道路能否合法通行是两回事；在虚构设定中，指定路线和装卸月台均可合法使用。不允许采取不安全的捷径或未经批准到场，迟到也不能靠缴罚金自动获准，且没有备用应急资源。实际发生延误时，需要重新评估，没有哪项补救措施能保证恢复原计划。Google 技术文档是模型的一手说明，不是配送表现的证据。Solomon 1987 文献的大学版本无法访问，出版方只提供摘要；两者都不计入已阅读的实质性来源。另已阅读五家机构提供的资料。
