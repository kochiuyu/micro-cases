IS-47 · 香港 · 15分钟 · 云服务计费 · 用量计量 · 成本敏感性

服务器更便宜，账单也更低吗？

一张云服务账单，不止一项计量

谷歌云的 Cloud Run 文档区分了几类资源的用量费用。亚马逊云科技分别列出 Lambda 按请求次数和运行时长计费的要素，并另行说明用量承诺。一家香港照片冲印店拿到两份虚构方案，港元费率也是编造的，并非云服务商的报价。

课堂决策

两份方案的文件保留条件、峰值吞吐量、客户响应时间和服务质量都相同。Flex 分别按请求次数和 CPU 时间收费。Reserved 按月收取固定套餐费，涵盖所列任一工作负载下的全部计算用量和请求。最低承诺期为一个月。冲印店必须在同一个即将到来的月度续约节点二选一，无须支付切换违约金。

首次试计量显示：调用量为2百万次，CPU 用时100,000秒，向客户发送的数据量为300 GB，存储用量为50 GB·月。计费用量已考虑取整。两种方案的用量相同，网络传输费率则按各自报价计算。假设没有税费、抵扣额、支持服务费、罚金或其他费用。

根据首次完整的试计量，你会推荐哪种方案？算出各自的账单总额，并说明计入出站传输费后，原本只看计算费用得出的价差会怎么变。

第二轮 · 多了一项资料

还是这次续约前测试，现在把内部队列短暂中断后的重试也算了进去。整月预测用量升至2.5百万次调用和180,000 CPU 秒，但出站字节数和保留的存储量都没有增加。作业在内部重放，Reserved 套餐仍能覆盖全部负载。

你的决策

你会改变选择吗？如果调用量为2.5百万次，传输和存储用量不变，CPU 总用时达到多少秒时，两种方案的费用相同？

看完整报价

按首次试计量，Flex 的费用为 160 + 150 + 360 + 30 = 700港元，Reserved 的费用为 650 + 90 + 30 = 770港元。Flex 仍便宜70港元，但计入出站传输费后，它在计算和请求费用上的优势从340港元缩小到了70港元。

按变动后的用量重算

计入重放后，Flex 的费用为 200 + 270 + 360 + 30 = 860港元。Reserved 仍是770港元，因此现在选 Reserved 能省90港元。Flex 多出的160港元中，40港元来自调用次数增加，120港元来自 CPU 用时增加。

两种方案费用相同的用量

调用量为2.5百万次时，Flex 除 CPU 外的费用是590港元，与 Reserved 的总价770港元相差180港元。按每秒0.0015港元计，这笔差额可支付120,000 CPU 秒。低于这个用量，Flex 更便宜；高于这个用量，Reserved 更便宜，前提是套餐仍能覆盖全部负载。

教师说明

问学生：为什么用一个固定数值估算计算费用，和用仪表板查看去重后的客户订单数，会以不同的方式漏掉同一个问题？请学生索取一份计费明细，列出每个计量项目的单位、用量和费率，并确认账单月份和网络路由与比较所用的口径一致。

所列费率和方案均为虚构，不构成产品建议。无须查询市场报价。

  1. Google Cloud, Cloud Run pricing。说明不同资源如何按用量收费，以及计费粒度；并非本练习的报价。
  2. AWS, Lambda pricing。分别说明请求量和运行时长，并在适用时补充网络及数据传输条款。
  3. Google Cloud, billing export。标准版和详细版导出都说明了用量、SKU、费用、币种和资源级字段。
  4. AWS, how Savings Plans apply。示例区分承诺用量和未纳入承诺范围的按需用量，两者都不等同于案例中的虚构固定套餐。
  5. Google Cloud, invoice cost details。费用表按账单周期列出明细，并提供 CSV 文件，便于把用量估算与账单核对。
