# ENT-01–ENT-50 terminology

Entrepreneurship, innovation and family business. English is the fact source. Simplified Chinese is written for mainland teaching; traditional Chinese is written for Hong Kong. The two Chinese versions are drafted separately from the English. Figures, case order and legacy case numbers are unchanged. This glossary was drafted with the OpenAI Batch API (gpt-6.2-sol) from the 50 English cases, edited for the site conventions below, and used for every case in the area. Names marked unverified, and the flagged items at the end, still need faculty review.

Conventions carried over from Finance, Operations, Marketing and Accounting:

- Interface strings reuse the Finance wording: 全部案例 / 全部個案, 演示模式 / 簡報模式, 打印学生讲义 / 列印學生講義, 课堂决策 / 課堂決定, 你的决策 / 你的決定, 教师说明 / 教師說明, 第二轮 / 第二輪, 来源与案例假设 · 选读 / 來源與個案假設 · 選讀, 微型案例 / 微型個案, 上一个案例 / 上一個個案, 下一个案例 / 下一個個案. Area label: 创业 / 創業.
- Debrief headings and the word debrief are 讲评 (zh-cn) and 講評 (zh-hk), as on the Finance pages. 复盘 / 復盤 is not used.
- HK$ amounts are written as the same figure followed by 港元 (HK$20 → 20港元). Other currencies keep their code or symbol as printed.
- Dates follow the Finance form on main after #13: 2024年7月29日, 2024年7月, 8月5日. A month standing alone with no year or day stays in characters (七月) so no figure is added. English number words, weekdays and ordinals stay as Chinese numerals; printed digits stay as digits.
- zh-hk is formal Hong Kong written Chinese (government releases, newspapers, university teaching notes), not a character conversion of zh-cn, not Taiwan usage and not colloquial Cantonese: 瓶頸 not 樽頸; 甚麼, 裏, 為, 線; 品質 for quality (zh-cn 质量); 資料 for information, except the fixed Hong Kong terms 資訊科技, 資訊系統, 資訊保安; 軟件, 網絡. 公里 is allowed. Other words containing 里 (e.g. milestone 里程碑, Delhi) are avoided in zh-hk because the language test bans that character outside 公里: milestone is 階段目標 and such names stay in Latin script.
- Source-link titles stay in English. Company, product and fictional names stay in Latin script unless an established Chinese name is listed below. Snow Town stays in English, as already decided on the Finance pages.

| commercial milestone / conditional order / customer acceptance | 商业里程碑／附条件订单／客户验收 | 商業階段目標／附條件訂單／客戶驗收 | ENT-41 分开看签函、下单条件、验收和付款。签署文件不自动等于无条件订单或可用现金。 |
| pre-order / refundable deposit | 预购订单／可退还的预订款 | 預購訂單／可退還的訂金 | ENT-49 收款时仍是预订，客户可全额取回款项。简体不用可能带有特定法律后果的「定金」；隔离保管不等同第三方托管。 |
| responsible wind-down / commitment mapping / consented handover | 负责任地结束经营／梳理既有承诺／经同意的交接 | 有序結束營運／梳理現有承諾／經同意的交接 | ENT-20 有偿付能力，重点是逐项安排谁履行、何时履行及需谁同意，不是破产清算或单方转移客户义务。 |
| asset bundle / net recovery | 组合出售的资产／净回收金额 | 組合出售的資產／淨收回款額 | ENT-46 比较列明移交范围的报价，扣除清场成本；不是所有资产都随报价转让，也不是会计账面价值。 |
| revenue architecture / fixed fee / outcome-linked fee | 收入模式设计／固定收费／与成效挂钩的收费 | 收入模式設計／定額收費／與成效掛鈎的收費 | ENT-24 服务范围相同，差别是收费依据；不能把成效挂钩收费写成服务方保证结果。 |
| outcome attribution / baseline | 成效归因／基线 | 成效歸因／基準水平 | ENT-24 有可量化的变化不等于变化可归因于供应方。客户投入和条件变化均可影响结果，节省工时也不等于节省工资现金。 |
| service productisation / scalable delivery | 服务产品化／可规模化交付 | 服務產品化／可擴展的服務交付 | ENT-25 通过明确服务范围和重复使用的组件扩大交付，不要求每家客户的诊断相同，也不取消品质审核。 |
| service blueprint / customer-facing and supporting work | 服务蓝图／面向客户的工作与后台支持工作 | 服務藍圖／面向客戶的工作與後台支援工作 | ENT-25 区分客户可见的接触环节及其背后的准备、交接和审核，不把蓝图等同于顾客旅程图。 |
| new-venture legitimacy / audience-specific signal | 初创企业的组织合法性／面向特定受众的信号 | 初創企業的認受性／面向特定對象的訊號 | ENT-26 的 legitimacy 指受众觉得企业值得认真对待和支持，不是法律合规；奖项或背书也不能代替产品证据。 |
| freemium / free trial | 基础免费、增值付费模式／免费试用 | 基本功能免費、增值功能收費模式／免費試用 | ENT-36 区分按功能设置免费层和按时间、用量限免。试点内不限用不代表试点结束后永久免费。 |
| cross-subsidy / referral contribution | 交叉补贴／转介带来的边际贡献 | 交叉補貼／轉介帶來的邊際貢獻 | ENT-36 区分免费用户直接升级和其转介带来的付费贡献；不能把转介价值写成已付的推荐佣金，也不能重复计算。 |
| one-time purchase / subscription / support commitment | 一次性购买／订阅／支持承诺 | 一次性購買／訂閱／支援承諾 | ENT-48 继续使用已购版本不等于一直享有人工作业支援；按两种收费方案分别写清资格、期限和成本。 |
| customer cohort | 同期客户群组 | 同期客戶組別 | ENT-48 按同一纳入时点及观察期跟踪客户；不能把 cohort 当作按需求细分的目标客群。 |
| contribution / operating contribution / cash contribution | 边际贡献／经营边际贡献／现金贡献 | 邊際貢獻／營運邊際貢獻／現金貢獻 | 一般 contribution 沿用 OPS，扣除题定变动成本；ENT-43、ENT-48、ENT-50 各按题定口径，不自动写成利润、收入或法定现金流指标。 |
| customer concentration / renewal risk | 客户集中度／续约风险 | 客戶集中度／續約風險 | ENT-50 依共同续约决定归集有风险的现金贡献；合约份数、表面买方数和独立决策数可能不同。 |
| franchising / franchise fee / royalty | 特许经营／加盟费／持续特许权使用费 | 特許經營／加盟費／持續特許權使用費 | ENT-43 区分初始收费和持续收费；royalty 的计费基数依题示条款，不推定一律按利润计。 |
| replication test | 门店复制试验 | 店舖複製測試 | ENT-43 在第二地点交由受聘经理营运，以测试不靠创办人驻店能否复制；不是已经售出首个加盟权。 |
| escalation of commitment / sunk cost | 承诺升级／沉没成本 | 承諾升級／沉沒成本 | ENT-40 指为了维护旧决定而忽略新证据，不是所有继续投入都不合理。不可回收的旧投入不进入下一轮的增量比较。 |
| process automation / exception review | 流程自动化／异常复核 | 流程自動化／例外個案覆核 | 沿用 OPS 的 exception 译名。ENT-45 工具只填常规草稿字段；例外覆核和最终放行审核不能省略。 |
| cost threshold / volume mix | 成本临界点／业务量构成 | 成本臨界點／業務量組合 | ENT-45 的成本交叉点取决于常规与例外文件的数量比例，不是收入与成本相等的盈亏平衡点。 |
| tooling ownership / supplier switching / compatibility | 工装所有权／更换供应商／兼容性 | 工裝所有權／轉換供應商／兼容性 | ENT-47 的具体工装是模具；所有权、实际保管、取回权及能否在新厂使用是四个不同问题。 |
| expected cost | 期望成本 | 預期成本 | ENT-47 按个案给定概率对各情形的成本加权；不是确定报价，也不是最坏情形的成本。 |
| opportunity cost | 机会成本 | 機會成本 | ENT-03、ENT-44 指因占用开发能力或让出渠道而放弃的最佳可行替代方案的价值，不仅是新增现金支出。 |

## Flagged for faculty review

- ENT-01、ENT-14、ENT-46：faculty 应核对出售标的。沿用品牌或家族名称的权利、出售全部股份、出售指定资产不是同一件事；正文不要将「出售」一律扩写成「出售公司」。
- ENT-02：second 可表示第二届或第二轮；PropTech proof-of-concept programme 在所给段落中是描述性写法。核对新闻稿正式名称及届次前，不拟造带书名号的中文计划名。
- ENT-03、ENT-04、ENT-05：节录缺少部分背景或方案原文，ENT-03 还出现孤立句点。回查完整英文以确认企业版称谓、奖项正式名称和归属条款；不从资本化词表拼补。
- ENT-04、ENT-42：support、award、grant 都不能机械译成「已收到的补助金」。ENT-04 明定合资格账单到期时可用支援，ENT-42 则明定虚构资助先支后领。
- ENT-05：如完整个案使用 vesting cliff，按实际条款区分「首次归属前的最低服务期」和「到期一次归属的份额」；不要把 cliff 译成试用期，也不要补入期权或回购机制。
- ENT-07、ENT-22、ENT-49：pledge 是众筹承诺；reservation 是预订；order 才是订单。funded 在活动语境可指达到筹资目标，不能据此写成资金已到账、已交付或已无退款责任。
- ENT-08、ENT-33、ENT-44：香港正文的 licensing 用「授權」，文件可称「授權協議」。许可、再许可、权利转让和渠道独家分别处理；不得把授予某项权利译成整件产品可自由销售。
- ENT-11：Hong Kong Techathon、Ideation 暂留原文；如完整来源给出当届正式双语名称再补。不要把两者当成同一计划。
- ENT-12、ENT-27：ENT-12 的指定用户评分、账户层面的重复使用及团队成员反馈不是同一指标。ENT-27 若 take-up 实为接受某个试点方案，用「接受率」，不自动改作长期采用率。
- ENT-13、ENT-41：Co-Development and Investment Conference 尚未据所给材料核实大会中文自称，保留英文；ENT-41 的 first 依该处原文保留，勿擅自补进其他个案。
- ENT-14：背景交易的 earn-out 与后续盈利挂钩，虚构交易的额外付款与订单目标挂钩。统一用「或有对价／或有對價」，不要两处都写「盈利对赌」。
- ENT-17：effectuation 另见「效果推理」等译法；本表用「效果逻辑／效果邏輯」。written, paid commitments 须回查付款方、收款方和承诺起效条件，不译成客户已付费订位。
- ENT-18：Business Innovations Generator 未核实正式中文项目名，保留英文；cohort 在此指同一批学员或入选者，不套用 ENT-48 的「同期客户群组」。
- ENT-19、ENT-20：BDC 暂保留简称，完整机构身份以原链接为准。ENT-20 的 business.gov.au 指引属于澳大利亚；若全文另引香港税务局，分别标明司法管辖区。
- ENT-23、ENT-26：bricolage 的「拼凑／拼湊」是技术性用语，不评价服务粗劣；legitimacy 可按课程理论用「组织合法性／組織正當性」，但必须明确不是牌照、审批或合规状态。
- ENT-29、ENT-33：spinout 不宜一律写成「分拆上市」。过渡服务、许可和权利归属按原文分别陈述；尚在讨论的事项不能写成已经签约。
- ENT-31：若全文同时出现 complete offering、whole product 和 product，先确认前两者是否指同一教学概念；都不能未经判断缩为实体产品本身。
- ENT-34–ENT-37：名称抽取含粘连的说明及金额片段，如「Covering CNY180」「Subtract NT」「R40000」。按完整英文核对断句、货币符号、变量和数字；不要把这些片段当专名或自行补币种。
- ENT-37：若后文出现 research use only 或缩写 RUO，核对其是指定标示、拟议用途还是某条供应路径的描述。不要把研究用途写成笼统的审批豁免。
- ENT-38、ENT-41：paid trial 是真购买，但未必是常规采用；signed letter 要按文件实际性质译为签署函件、意向书或订单，不凭签名推定已通过验收或可确认付款。
- ENT-39：cross-purchase 如涉及分期或借款，逐项标明谁买股、谁融资、谁承担偿付；不要把股东间交易改写为公司回购。
- ENT-43、ENT-44：royalty 随具体合同语境区分「特许权使用费／特許權使用費」和「许可使用费／授權使用費」；除非英文明确按销售比例计费，不译作销售提成。
- ENT-45、ENT-46：ENT-45 的 release 是文件审毕后的「放行」，不是政府提交或软件发布；ENT-46 的 clearance 是清场，不是审批。若引用 Copy Application 按钮原文，保留其英文界面标签。
- ENT-47：Option Vendor 和 Option Own 是选项标签，不是供应商名称。标签可解释为「供应商持有模具」和「本企业持有模具」，并与计算表使用的选项标识一致。
- ENT-48、ENT-50：ENT-48 的 inventory 沿用「库存／存貨」；ENT-50 的 concentration 是按共同续约决定归集的内部现金贡献指标，不套用上市报告中的收入集中度定义。
