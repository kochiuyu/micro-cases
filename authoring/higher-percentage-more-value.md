# A higher percentage. More value created?

<!-- legacy-case-id: 362 -->

FIN-31 · Hong Kong · 15–20 minutes · Internal rate of return · Net present value · Mutually exclusive investments

![Two fictional workshop colleagues compare plain project folders beside a single empty assembly bay and differently sized unbranded display modules.](../higher-percentage-more-value-scene.jpg)

## A percentage and a dollar surplus answer different questions

Investment-appraisal education distinguishes the rate that makes a project’s net present value zero from the value it adds at the required return. Projects can rank differently on those measures when their scale differs.

Harbour Modules and every cash flow below are fictional. This classroom exercise supplies the risk assessment and funding limits; it is not an investment recommendation or evidence about a real company.

## Opening decision

You advise fictional Hong Kong exhibition workshop Harbour Modules. It can accept either a small display-module project S or a large project L for the coming year, or decline both. Both need its only available assembly bay and the customer will accept only one specification. They cannot be combined, divided, repeated or postponed.

Management’s objective is to add the most present value among feasible choices. It has HK$100,000 available today after protecting ordinary operating cash. The supplied annual required return is 10% for both projects: the case assumes comparable risk. No additional funding is available.

Each project has one payment today and one forecast net receipt exactly one year later. Receipts include all operating costs, taxes, working-capital release and disposal proceeds; there are no other project cash flows. Unused funding is returned to the owner today and creates no additional project NPV.

## Evidence

| Project | Payment today | Net receipt after one year |
| --- | --- | --- |
| S: small specification | HK$40,000 | HK$52,000 |
| L: large specification | HK$100,000 | HK$124,000 |
| Decline both | HK$0 | HK$0 |

For this one-outflow, one-inflow pattern: IRR = receipt ÷ payment − 1. NPV at 10% = receipt ÷ 1.10 − payment. IRR is not defined for declining both; its project NPV is zero.

**Student question:** Choose S, L or neither with HK$100,000 available. Report each project’s IRR and NPV, then explain which measure answers the stated objective.

## Round two

Before commitment, the owner withdraws HK$30,000 for an unrelated obligation. Only HK$70,000 is now available for this decision. The withdrawal is the same whichever project is chosen; it is not a project cost.

No loan, extra owner contribution, staged payment or smaller version of L is available before the decision deadline. All project cash flows, their risk and the 10% required return remain unchanged.

**Student question:** With only HK$70,000 available, choose S, L or neither. Has L’s NPV changed, or has the set of feasible choices changed?

## Debrief · More percentage, less present value

S has IRR = 52,000 ÷ 40,000 − 1 = **30%**. L has IRR = 124,000 ÷ 100,000 − 1 = **24%**. Both exceed 10%, but that does not rank the value added.

S has NPV = 52,000 ÷ 1.10 − 40,000 = **HK$7,272.73**. L has NPV = 124,000 ÷ 1.10 − 100,000 = **HK$12,727.27**. Both fit the opening budget. Choose **L** for the stated value-maximising objective, not both: the projects are mutually exclusive.

## Debrief · Examine the extra commitment

Moving from S to L requires HK$60,000 more today and produces HK$72,000 more after one year. That incremental commitment earns 20%, above the supplied 10% requirement. Its NPV is 72,000 ÷ 1.10 − 60,000 = **HK$5,454.55**, the difference between project NPVs before rounding.

This is a comparison, not a third project that can be bought separately. L wins here because its extra commitment creates positive value, not because larger projects are always better. The unused HK$60,000 under S has not been lost; it remains the owner’s money rather than being counted as project value added.

## Debrief · A good project can be infeasible

Choose **S** in round two. Its HK$40,000 payment fits HK$70,000 and its NPV remains positive. L needs HK$100,000 immediately and is short of funding by HK$30,000. The expected future receipt cannot fund today’s payment.

L’s calculated NPV is still HK$12,727.27; no project input or discount rate changed. What changed is feasibility. Choosing S now does not prove that the higher IRR was the right ranking rule all along. It is the only feasible positive-NPV project in the supplied choice set. Declining both adds zero project NPV.

## Instructor note

Minutes 0–4: take a first vote and ask students to calculate both measures. Minutes 4–9: compare the percentage ranking with the present-value ranking and test the extra HK$60,000 commitment. Minutes 9–13: reveal the funding withdrawal and vote again. Minutes 13–18: separate project desirability from feasibility.

Ask S supporters in round one why a larger percentage necessarily means more dollars added. Ask L supporters in round two where today’s missing HK$30,000 comes from. Ask both groups what evidence would be needed to change the supplied risk or cash assumptions; do not invent financing to escape the stated constraint.

This case isolates IRR scale conflict for two same-horizon choices. Unlike FIN-08 it is not a payback comparison; unlike FIN-19 it does not optimise a portfolio of independent projects. The one-period formula avoids intermediate reinvestment assumptions and multiple-IRR complications.

## Sources and case assumptions · optional reference

All information needed for classroom decisions is provided above. Sources are optional reading.

Original fictional workshop, project specifications, funding withdrawal and cash flows. One-year horizon; single outflow followed by a single inflow; projects mutually exclusive, indivisible and not repeatable or deferrable. Both have a supplied 10% required return and comparable risk. Net receipts already incorporate all relevant operating, tax, working-capital and disposal cash flows; no separate interest expense is added. Ordinary operating cash is protected outside the stated available funding. Unused capital is returned to the owner immediately; no other positive-NPV use is available in this exercise. Round two changes only available funding. Round final money results to two decimals. Sources support methods, not these hypothetical forecasts.
