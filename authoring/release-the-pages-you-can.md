# One request. Which pages can you release?

<!-- legacy-case-id: 588 -->

GVR-49 · Hong Kong · 15 minutes · Information access · Partial release · Verification workload

![Two reviewers compare papers and three coloured folders at a service counter.](../release-the-pages-you-can-scene.jpg)

## An access request can have more than one answer

Hong Kong’s Code on Access to Information sets out a process for access to government information and includes grounds for withholding some information. The exercise uses a fictional service office and its own rules. It is not a ruling on whether any real document should be released.

## Opening decision

Jin reviews an access request sent to a fictional Hong Kong community service office. It asks for three PDF records. Nothing is already public. Treat each record separately. For this case only, ordinary operating data is releasable; contact details of private individuals and wholly confidential evaluation sheets must not be released.

File A contains only releasable operating data. File B has a stand-alone public aggregate table and a separate narrative in which contact details can be removed without changing the narrative’s meaning. File C is wholly exempt under the supplied case facts. File A needs independent review, File B’s table needs a separate release check and its narrative needs masking plus independent verification that the withheld information cannot be recovered, and File C needs a brief reasons notice.

All work uses the same queue and is sequential. There are 60 staff minutes before the same-day deadline. Send material that can be released under the stated rules as soon as the required checks are done. Prepare File C’s notice today; if File B cannot safely be sent today, acknowledge the delay and state the next review time. Routine package assembly and updates take no extra time in this exercise.

## Evidence

| Fictional work item | Minutes |
| --- | --- |
| A: independent release check | 15 |
| B: stand-alone table release check | 10 |
| B: narrative masking and independent verification | 25 |
| C: record and explain the grounds for withholding | 10 |

**Student question:** Can Jin complete a safe response on all three records today? Specify what is released or withheld and why the presence of exempt material in File B does not determine the fate of File A.

## Round two

The verifier’s planning scan finds hidden searchable contact details in B’s narrative. The approved correction and new verification add 15 minutes to the narrative’s original 25, but do not affect B’s stand-alone table. The scheduled queue has not started. The deadline remains 60 minutes away and partial release is allowed.

**Student question:** What can Jin safely deliver today, what should be deferred, and how many additional queue minutes would make today’s complete response feasible?

## Debrief · Give each document its own decision

The required queue is 15 + 10 + 25 + 10 = 60 minutes. Release checked File A in full and both releasable parts of File B once their respective versions are independently verified; send reasons for withholding C. A safe partial response to one document does not decide a different document.

## Debrief · Appearance is not verification

B’s narrative now takes 25 + 15 = 40 minutes. The full response needs 15 + 10 + 40 + 10 = 75, or 15 more than available. Release A and B’s checked stand-alone table, and send C’s reasons notice. There are 25 minutes left for the narrative, not enough to release it today. Acknowledge the delay and set the next review time.

## Debrief · Preserve a release trail

Keep the source files separate from approved release copies. Record what was sent, the reason for withholding, reviewer, version and timing. If the narrative can safely be processed in stages, use today’s spare capacity or secure independent queue capacity; never substitute a visual-only check.

## Instructor note

Use 2 minutes reading, 4 on document decisions, 4 to reschedule, and 5 to test whether partial release still has meaning. Do not use real documents or assume the case clock is the real statutory or code deadline.

## Sources and case assumptions · optional reference

All information needed for classroom decisions is provided above. Sources are optional reading.

These files, restrictions, clock and reviewer resources are fictional. No claim about the legality of release, exact redaction technology or classification of any real document is implied.

- [HKSAR Government, Code on Access to Information FAQ](https://www.access.gov.hk/en/faq/index.html). Explains the request process and what their Code provides.
- [HKSAR Government, Guidelines on Interpretation and Application](https://www.access.gov.hk/filemanager/content/codeonacctoinfo/guidelines.pdf). Provides operational guidance for requests, processing and withholding.
- [HKSAR Government, Code on Access to Information Part 2](https://www.access.gov.hk/en/codeonacctoinfo/part2.html). Lists grounds that may justify withholding information, including privacy.
- [HKSAR Government, Code on Access to Information Part 1](https://www.access.gov.hk/mobile/en/codeonacctoinfo/part1.html). Sets out procedural provisions, response timelines and review mechanisms.
- [Office of The Ombudsman Hong Kong, Policy on Access to Information](https://www.ombudsman.hk/wp-content/uploads/2023/08/Policy-on-Access-to-InformationNov2022.pdf). Primary text for the Office’s own records request policy and limits.
